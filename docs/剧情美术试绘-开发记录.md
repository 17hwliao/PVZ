# 剧情美术试绘与战地行动

本轮为0.5.2之后的本地开发，沿用原有分支与三套界面风格。未创建远端分支、PR、标签或Release，未覆盖既有安装包。

## 已实现

- 豌豆、寒冰射手的强硬看守面孔；坚果完好、一级与二级破损三套试绘。
- 普通、路障、铁桶使用文明同胞面孔，带梳理过的头发、单片镜和小创可贴。沿用原有西装、护具、行走、攻击、受击与退场动画。气球、矿工、仙人掌、大嘴花、向日葵保留原画。
- 选卡头像从同一渲染器生成，随“剧情试绘/原版角色”切换；设置兼容旧存档。三套木牌、石刻、来信界面仍保留。
- 墓碑列添加透明边缘的苔石、旧铁栏、暖灯；五座墓碑使用不同原版轮廓与损伤状态，破碎后仅剩地面残基；仅墓碑显示血量。
- 六个关卡添加地面接应行动：饭盒、四个囚室、造谣档案。地面单位处于目标前后48范围，且没有交战或出土时累计2秒；完成给予一次40/50能量与剧情对白。完成后不再重复发奖。
- 新兵种仍在胜利后加入；其他路线获胜时照常在战后带走囚室同胞。接应不增加新失败条件；进门、两路小车、五碑全碎与每碑一次500奖励保持原契约。
- 新画图缺失时回退原画或文字，并在设置中提示。剧情提示允许换行；战地行动提示参与现有机制栏显示条件。

## 验证证据

完整既有与新增测试共92项通过；11个JS语法检查、318个本地资源引用检查通过。新增8项包含接应资格、两秒累计、暂停、一次奖励、胜后解锁、实例隔离、透明PNG裁图边界、原动画换图与回退、画风保存及资源失败恢复。既有七关连续推进、分支、小车、护具、旧存档与原版资源溯源检查通过。

在实际桌面浏览器检查了选卡、开战、战地提示、新角色与墓碑列、设置中两种角色画风切换、放大动作图鉴和坚果濒危形象。截图保存在工作区outputs下的“剧情美术试绘-*”。实际运行中观察到首关饭盒行动完成；长时间未继续部署会依原规则失守，未将截图过程记为通关。

本轮未验证PC原生窗口、安卓设备或窄屏排版；模拟与浏览器证据不替代这些环境。未进行新的全量代码Review。

## 美术来源与范围

五张新透明PNG使用内置image_gen生成，文件为assets/story-art/*-v1.png。提示词、参考和SHA256见同目录provenance.json。原版资产与原版EXE未改动；新图挂接既有动画，没有声称重新绘制全套逐帧动作。

本轮不重新打包或发布旧名0.5.2工件。后续确定画风后，可统一其余角色与战地道具，再归并为一个有明确范围的交付。
