# 指挥交互、连续移动与智能攻防

2026-10-26 · `squad-command-20261026a`。继续当前营救开发，未打包、推送或发布；本轮为功能实现及回归检查，不是全仓代码Review。

## 玩家怎样操作

1. 准备阶段先选博士藏身的栅栏，再安排三队，60秒可提前结束。
2. 点击场上的僵尸或脚圈选队，或按1—3；点击空地／补给碑下令。重复点同一重叠队形保持当前选择，不随机切队。
3. 两队同格时显示“队伍1／队伍2／合并／分开”等经典木牌；三队同格显示三枚选择键。按钮跟随实际绘制脚点，避免点击穿透。
4. “合并”组成协同联队，共同行军、等待和接战；固定三队、每队最多三人的身份与伤势保留，不把六人塞进一个三人槽，也不复制成员。联队按共同可走的路径与最慢成员速度行动。
5. “分开”解除联队并待命，之后可以分别调遣。即使联队暂时不在同格，原队伍按钮条仍有“分开联队”。
6. 要汇合到另一队所在格，先明确点击“推进／转线／准备布阵”，再点目标队所在格；一次目标点选结束后恢复点击人物选队。方向键＋回车也保留。

右侧“当前目标”随真实状态切换藏身、选队、接碑、开门、返营和失散接应，显示实际补给数量，不再让玩家从整页长说明里猜下一步。小屏把同一组队伍木牌放在画布紧下方，保留44px触控高度；桌面原位避让角色与高气球。

## 移动改变了什么

- 移动中重定目标时，比较当前合法格边两端的总路径长度；可以沿同一条边立即反向，不再先走到旧目标格才回头。
- 到达格点后继续消耗本帧剩余移动距离，消除每格反复降速。旧实测0.032格的正常帧会在格点降到0.008；修复后中间格点保持完整预算，只有最终停车截断余量。
- 寻路仍遵守墙、房门／补给实体、固定桥和法定换行通道。植物不计入寻路障碍，推进遇植物就正常接战，清除后继续，不另找避开植物的路。
- 联队下令先检查全部成员共同可走的路线，失败时不部分执行。水生队与陆生队合并后不能带陆生成员下水。

原有地形中部分第七列格被篱墙与补给夹成孤格，导致某行没有任何合法直射位。实际营救关补通第七列前线纵向联络，地下南端清掉该列堵口，玩家与AI都能使用；房门与补给位置不变，主篱墙缺口和水域规则仍有效。此改动只接入实际营救关，地图册的进阶布局仍是设计稿。

## 植物人机

部署、换行和开火共用公开火线判断。直射被篱墙或屋脊挡住时不白白发射，卷心菜保持抛射身份；已有植物只沿自身列慢速换行，未增加横向自由行走。

人机按可见队伍、公开补给与五行栅栏分配射位，减少重复覆盖同一行。已破栏通道仍接受同线压制与轮换，不能把“击碎栅栏”误认为已经命中博士。

当旧射位失效且周围安全，人机可以撤下旧植物（无退款），按原本卡片费用、冷却及所需底座重新布防；有15秒重部署节拍。它没有增加阳光、免费搬植物、改变攻击伤害、延长蘑菇射程或把隐藏博士坐标交给部署逻辑。开局仍是500阳光与五株免费场外无敌向日葵。
