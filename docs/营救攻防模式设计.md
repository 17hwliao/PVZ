# 营救攻防：小队指挥与动态战线

2026-10-24 · 玩法提案，尚未替换可玩版战斗规则。

最新确认：墓碑改为分布在路线上的补给节点，承担前进补兵、一次物资和整备功能；撤离营地单独标识。落地的关卡表、博士立绘与交互分镜见[关卡与战场展示](营救攻防-关卡与战场展示.md)。

用户本轮要改变战斗结构。此前“在静态防线前选两路投入，再加少量增援”的方案不作为新模式方向。本提案保留经典草坪和卡片的外观，将主循环改为：**侦察 → 夺取前哨 → 组织攻坚 → 救出同胞 → 守住返程通道并撤离**。

## 玩家操控什么

玩家最多指挥三支小队，每队三个成员位置。卡片仍表示一个具体僵尸，部署时加入指定小队，按成员付费；不会一张卡无成本变出一整队。小队成员自动移动、攻击和维持前后站位，玩家下达四种命令：

| 命令 | 实际操作 | 战术意义 |
| --- | --- | --- |
| 推进 | 选小队，再点一处可达路段或目标 | 沿路线前进，遇敌交战；不默认一路走到底 |
| 驻守 | 点前哨、路口或撤离口 | 原地接战、保护通道，放弃继续深入的机会 |
| 转线 | 经标出的联络通道进入相邻行 | 绕后、避开强火力或支援另一队；不是瞬移 |
| 撤回 | 返回仍被控制的整备碑或右侧营地 | 进入整备，花能量修护具后再上阵；返回途中仍有风险 |

指挥暂停可以查看防线和下达命令，恢复后执行。普通操作不要求同时微操九个单位；需要手动选择的是路线、目标和进退时机。僵尸、植物不加血条，伤势通过护具、姿态和声音表现。三队成员数量、冷却与整备状态显示在经典卡槽中，墓碑继续独立显示血量。

## 草坪还是五行，但路线可以改变

五行十列保留。第一列附近是植物控制区，撤离营地位于右侧。补给碑沿行动路线分布，初期三座，后续四至五座，不再固定排成最右侧一整列。中间标出两条纵向联络通道，允许小队在指定位置上下转线；不是五条彼此隔绝的直道。

联络通道属于地形，不允许植物在整个通道上随意落种，把所有路线瞬间封死。植物可守住通道出入口，僵尸可以交战、换另一个出口或退回。

三个关键地点具有不同作用：

- **前哨**：占领后允许在这里补充队员，缩短补兵距离；植物夺回后停止前线部署，场上同胞不会凭空消失。
- **补给仓**：给一批有限补给，并提供整备位置；不无限产钱。是否绕路取补给，要和前哨压力比较。
- **囚室**：需要地面队伍清除附近看守后开门，解救目标进入队伍返程。飞行侦察或潜行绕后不能直接跳过开门与接应。

不是每关都放满三个据点。教学关先用“一个前哨＋一处囚室”，再增加补给仓与第二条返程路线。

## 植物怎么主动战斗

植物本体仍以扎根射击、阻路、修补为主，前线通过**落种、补位和重建**改变。每场战斗有有限的阳光预算和支援牌，不无限刷兵，不读取玩家尚未执行的命令作弊。

每次支援先给出落种位置、种类与成长预告，玩家有时间决定继续攻坚或转线。不得直接在僵尸脚下生成满状态大嘴花；落点须为空且成长过程可见。植株从成长到生效的规则统一。

植物有三种公开行动，按有限预算择一执行：

1. **补位**：前排被打穿后，尝试在合法后方空格种坚果或补一名射手。
2. **反制**：空路受到威胁时准备仙人掌；重甲在某路集结时准备近战看守。反制要有预告和费用，不能每次都立即抽到完美答案。
3. **夺回通道**：将一次支援投入玩家控制的前哨附近，形成可交战的占领压力；不是直接把据点所有权切回去。玩家可以留下驻守队，也可以让出前哨、保全正在返程的同胞。

植物占点需要守卫实际控制据点并持续占领；僵尸在点内接战时占领停止。双方都能打断夺点，伤害不会在场外直接扣据点。前哨不另加隐藏耐久。

## 一局到底怎么变化

示例关「把送药人带回来」，先采用五分钟左右的流程作为原型目标，具体时长待实玩验证：

| 场面 | 玩家正在做的事 | 接下来为什么要改决定 |
| --- | --- | --- |
| 开局 | 一队带路障夺中段前哨，另一队保护通道，留能量补人 | 前哨决定以后从哪里补兵 |
| 前哨到手 | 在前方补一名队员，准备攻囚室 | 植物预告在主路后方补位，直冲将变成前后夹击 |
| 攻坚 | 一队正面接战，另一队经联络通道绕到支援植物侧面 | 要决定先切断支援，还是趁窗口开门 |
| 开门 | 囚犯获救，必须选择返程方向 | 植物把剩余支援投入前哨附近，原来的安全路可能保不住 |
| 返程 | 一队掩护、一队驻守路口；受伤成员可撤回整备 | 前哨、补给与护送争用有限的人手，不能同时占完所有地方 |
| 最后撤离 | 带获救者抵达右侧撤离营地 | 可以放弃前线据点，需要沿仍能通行的路线接应返程 |

胜利是完成营救并把人接回，不要求清空全图。也不因一位普通僵尸碰到房门就提前结束这一流程。没有额外的“留在敌人家里等倒计时”收尾。

## 小车和墓碑怎么变得有战术意义

### 小车是战场装置

营救攻防中的小车不再是“发动两辆就通关”的计数器。它有可见警戒区与发动预告，启动后沿整行扫过。

玩家可以选择在联络口换线避让、等待它驶离，或接近控制位置将其关闭。关闭需要一段无人交战的地面操作；付出的代价是占用小队和路线时间，不是强制送人去死。小车离场只改变该路危险，不直接判定完成营救。

这是新模式提出的胜利规则变化。现有可玩版的“进门／两车”规则本轮未修改。

### 墓碑是沿途补给节点

按用户最新决定，墓碑分布在路口和返程路线，不作为固定一列的出口。前进碑提供补兵位置，物资碑只给一批资源，整备碑帮助撤回的同胞修护具。撤离目标是右侧独立标记的营地。

保留“全部墓碑被破坏才战败”的原则，作用对象改为本关沿线的三至五座补给碑。每座破坏仍释放一次500应急能量；失去的是该点的补给、整备或前线补兵能力，已有队伍不消失，地形通道不凭空封闭。营地不新增另一条隐藏生命条或失败条件。

夺回仍完好的碑恢复服务，不重复获得一次性物资。被摧毁的碑在本场不免费复原。反攻奖励、整备花费与据点功能需要新模式实玩验证，本轮交互分镜不计算这些数值。

## 共情通过行动建立

**同胞可以被保存下来。** 撤回整备保留的是同一个成员，而不是死亡后再购买同一张脸。整备消耗能量和时间，未到安全点前不能瞬间回血或离场。免费满血撤回、全额退款和重部署刷资源都不应存在。

**玩家必须给救援对象留人手。** 获救者自动沿玩家选定的已知路线走回出口。附近没有接应、受到封锁时，他停下躲避；敌方重新控制他所在位置后，可把他拘回最近的囚室。玩家能再次营救。这避免增加第二种不可逆失败条件，仍只在五碑全失时战败，同时让护送确实需要照应。

**目标不是让每个人都变成杀伤数值。** 普通同胞开门、搬物资，护具同胞掩护，空中和地下单位处理侦察与绕行。战斗中有人受伤、需要等待、需要被接应，是规则能表达的困难，不必不断插入说教对白。

**撤退也可能是正确答案。** 当前线攻势已经完成任务，玩家可以放弃据点、保护返程。没有为了评分必须把所有植物杀光的附加要求。

具名角色是否永久阵亡暂不加入。首个原型只保存本场成员与整备状态，不以未设计完成的跨关永久伤亡增加惩罚。

## 第一版只做这些

先制作一关可玩的闭环，不同时铺开全部图鉴：

- 普通、路障、铁桶三种现有僵尸；三支小队、每队最多三个成员。
- 推进、驻守、指定通道转线、撤回四个指令。
- 一个可争夺前哨、一处囚室、两条可选返程路线。
- 豌豆、坚果、向日葵三种植物；有限的补位与夺回前哨行为。首版不需要完整反制牌库。
- 一次有预告的小车危险；关门、接应、撤离组成完整任务。
- 路线补给碑的服务失效与500反攻奖励，场上单位仍可改走其他路线。

气球、矿工、巨人和僵王技能在这个闭环成立后扩展。巨型机甲适合成为队伍之外的支援核心，帮助打开路径，而不是取代三队的进退判断。四种机甲外观共用规则。

原型是否有趣，要看玩家是否因真实战况改变过路线、是否需要在驻守和推进间取舍、是否愿意花资源把受伤同胞带回来，以及是否确实存在两条合理打法。若只是换了据点名称，实际仍然是同一路不断出兵，就还没有达到本模式的目标。

## 本轮状态

本轮仅完成玩法设计，未把这些规则写入正式战斗引擎；没有宣称已完成可玩原型、数值平衡或视觉验收。原有故事、角色立绘与可玩七关保持现状，未打包、推送或发布。
