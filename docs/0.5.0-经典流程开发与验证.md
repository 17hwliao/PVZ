# 0.5.0 经典骨架与僵尸主题流程

日期：2026-10-22。沿用既有工程和main工作分支，落实用户选择的B路线。最低范围是主菜单→选卡→1-1对战→通道奖励，并将共用界面接入前两章七关。此文件同时记录本阶段范围和验收证据。

## 主要变化

主菜单使用提供版本的原版标题场景、木牌和石按钮，提供开始/继续、章节、档案与设置。首次从菜单进入序章；旧存档保留当前关卡、兵种、分支、来信和战后检查点。主菜单暂停战斗，返回时明确说明进行中的战斗从本关开局重来；尚未读完的奖励和战后故事可继续。章节选择与暂停菜单分开，未解锁关卡不能选择。

选卡页右侧显示实际开场植物阵型和数量，不常驻完整图鉴。和平/强攻切换时预览与统计一起更新。下方卡片只负责加入，上方卡片移除；重复点击已编入的下方卡片不再移出队伍。未解救卡片查看来源但不能编入。单位详情通过按钮、右键或550ms长按打开，可关闭并恢复焦点；键盘可读长资料。卡片加入有260ms飞入卡槽反馈，柔和模式直接完成。

对战保留五行与新增墓碑列，使用1200×720稳定战斗坐标；没有把玩法强行改成原版4:3。主菜单背景保持图像比例并裁切，奖励和章节底板保持4:3，边框采用原九宫格。选卡、角色、入口与弹道坐标没有更改规则。

选卡后出现半透明僵尸预览：入口合法时吸附实际出生点，其他位置或冷却/能量不足时显示无效反馈；右键、Escape取消。召唤后结束本次选择，继续召唤需要再次选卡；1—5、方向键、回车仍可使用。手机入口按下时展示相应行反馈。费用角标统一为现有僵王头像，移除太阳图标。植物与僵尸不加血条，墓碑保留血条；完整耐久数字按受击或选中显示。

防守碑破碎的500能量规则保持，新增能量飞入头像反馈；同帧多碑破碎合并显示总量。右下进度保持真实的小车离场与进门胜利判定，将原两面旗换成两枚小车标记，明确它不是波次倒计时。暂停菜单只保留返回、重选、设置与档案、返回主菜单四项。

1-1获胜显示通道开启、同胞通过的原版奖励底板，不伪造新兵种解锁。真正的救援关展示原版纱门道具移开、同胞走出和新卡出现；永久解救及战后检查点继续沿用既有存档契约。现有漫画、来信和前后对白保留。

接入六个原版短音效：按钮、提卡、出场、小车、墓碑与开场提示。默认声音仍关闭，可在设置开启并保存；宿主切后台或关闭声音时停止短音效。没有新增完整背景音乐。Android补充audio/ogg MIME；Electron本地协议开启媒体stream能力，参考[Electron官方协议文档](https://www.electronjs.org/docs/latest/api/protocol/)，不放开外网或CSP。
