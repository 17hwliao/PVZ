# 正式营救界面精简与阶段 Review · 2026-11-06

## 范围与结论

在最新主开发工程保留原有改动，完成四十关主冒险及共用七关营救的同一套经典单窗口布局。入口、操作、弹窗和相关状态经过本阶段 Review，已确认的问题已修复并定向复核。本次不是重新进行整个项目全量审计，也没有实施后续新玩法或调整战斗数值。

Git 起点为 `684f5b4fb72c5afac3b25ae251fea29761d02663`，复用 main；起点包含未提交的经典弹窗、上次 Review 修复和 Electron 源码启动成果，全部保留。Downloads 发布快照未作为功能基线。公共版本仍为 0.8.0 / 构建 800；本次依新增授权只推送源码，不生成包、PR、标签、Release，也不更改更新清单。

## 已完成的正式布局

- 顶部合并成关卡、物资、博士次数、阶段、三队图标和菜单。准备时有编队/出发，开战后收起。植物阳光与冷却只在左侧敌方情报牌区，不是玩家种植栏。
- 删除指南、未来设计按钮及自动指南等待、右侧整栏、底部命令日志、准备教学横幅、重复 HUD、正式关卡下拉框、版本/设计/坐标提示。必要命令转入场景小木牌和暂停菜单，没有新增折叠说明栏。
- 选择人物、脚圈或顶部队伍图标后可直接点格下令；单次选队只显示小“行动”旗，明确点击才展开命令。鼠标移动实时显示格子落点，不显示坐标数字；目标反馈画在角色下方。
- 同格木牌可分别选队、合并、分开；另保留驻守、回营、汇合、转队、气球落地和准备布阵。补给碑本地提供真实费用的回血/补员，错误在操作处短暂反馈。
- 编队为同窗三队卡槽，采用草稿事务，确认才替换配置；取消不扣资源。兵种解锁、预算、地形和每队三人约束继续调用模型。
- 保留序章、来信、营救对白和战后回信；菜单集中继续、重开、信件、解锁选关、设置及回主菜单。结果窗显示实际结果、下一关/重玩/返回；自动接续只在结算中出现，取消及失焦暂停有效。末关不弹设计宣传或回到首关。
- 原有木纹、石框、旧纸、卡牌、离线字体及按钮贴图继续使用。石板按钮九宫格保留短按钮边角，普通/悬停/按下/禁用反馈统一；没有全屏模糊滤镜。

统一逻辑窗口 1440×800 等比适配，战场仍用原 1200×720 坐标，裁切摄影机顶部 72、可见高度 600。地图五行十列、脚点、碰撞和路径坐标未改；不能单独横向拉伸背景。较小窗口留边等比缩放，正式战场无需页面滚动。

## 入口和状态边界

`terrain-campaign.html / rescue-design.html → game-window → rescue-design controller → model / painter / plant-economy / story UI`。四十关另加载地形、单位及 progress；七关保持独立规则。经典对线没有换成营救规则。

正式关卡从 progress 读取；只有明确 trial 才使用任意 URL 关号。编队、信件、菜单及结算共用单一 modal 所有权，嵌套返回不提前恢复战斗。native-pause/页面隐藏保留暂停；“继续”或明确出发才恢复。进度写入仍在真实胜利后，trial 不写正式进度；坏存档保留原文，不为移除指南制造已读/完成记录。

## 确认问题、修复与复核

这些是本阶段实际发现的问题，不将代码风格偏好计作缺陷。

| ID | 触发与真实后果 | 修复 | 定向复核 |
| --- | --- | --- | --- |
| U1 | 弹窗逻辑宽度超过小窗口时，浏览器默认 dialog 定位使卡槽/按钮偏出窗口 | 显式中心定位和统一等比缩放 | 960×640 实际截图、DOM 边界及编队操作 |
| U2 | 后期植物牌多时，左栏卡牌下部被裁切 | 按牌数使用紧凑两列高度，保持费用/冷却 | 后期地图截图、经济牌契约 |
| U3 | 通用石板按钮优先级覆盖僵尸卡包，横向 flex 令价格跑出卡面 | 恢复高优先级卡包背景、纵向排布和深色底价 | 实际编队截图、槽位预算操作 |
| U4 | 高频刷新重建木牌 DOM，鼠标/焦点目标变化 | 状态签名不变时复用节点 | 连续刷新保持节点与焦点；实际同格切队 |
| U5 | 同格刷新同时出现组木牌和大行动牌；第三队邻格经过时又会隐藏同格操作 | 同格按选中队实际格过滤，命令牌由明确操作打开 | 两队/三队、经过、合并/分开和 ID/伤势守恒 |
| U6 | 点击队伍自动打开大板，挡住下次下令；目标圈可画到下排人物头上 | 首次选队仅小行动旗；鼠标实时格提示，点击格避让；标记排到人物下面 | 真实画面、缩放坐标事件、绘制顺序、鼠标移出清除 |
| U7 | 补给窗打开后原碑被击碎，可能通过模型另一座近碑继续扣费治疗 | 操作时重新校验被点的碑、距离、状态和费用 | 破碑/邻碑相反条件、无扣款；真实回血补员 300→270→220 |
| U8 | 原模型将后排多处计为营地，UI 拦截其他行点营地为补员，不能正常回营移动 | 只有队伍实际靠近营地格才拦截，否则下达原命令 | 后排跨行到营地路径及补员限制 |
| U9 | 编队重开保留上次失败文案；关闭草稿有覆盖风险 | 每次新草稿清反馈，确认与取消分开 | 预算不足、取消、再次打开；原生移除后取消恢复 3/3 |
| U10 | 自动接续取消仍显示暂停；末关旧流程推广未实装设计 | 取消文案对应真实状态；末关停在结果 | 暂停/取消/下一关/末关、不写 trial 档 |
| U11 | 第一行带盆高仙人掌接近顶部裁切；反馈遮住已展开小牌 | 摄影机从 80 改为 72；反馈避让其他本地操作牌 | 高仙人掌发射、花盆、气球和本地补给截图 |
| U12 | 战后文章重复同一句后续文字 | 相同 camp/next 不重复拼接 | 战后回信和结算实际阅读 |

风险卡核查：加载失败使用可重试入口，不形成空白指南锁；确认/取消和单次结算保持状态守恒；同一对象刷新不抛失焦点；读档异常不被胜利覆盖；UI 数字来自模型费用/冷却/命中而非另一套数值。长期增长方面没有新增持久日志/队列，反馈与标记短暂过期，单次循环及监听随页面销毁。试验种子和本机运行库配置均在忽略目录，不进入产品或提交。
