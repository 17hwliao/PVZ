# 项目任务与完成状态 · 2026-11-06 更新

目标成品为 Windows Electron 桌面游戏，安卓使用单独的 WebView 容器。HTML、Canvas、JavaScript 是现有游戏的实现技术；PC 玩家从独立游戏窗口操作。浏览器入口保留为辅助预览，不再作为默认源码启动方式。

当前结论：已有可玩的本地开发版，完整五幕游戏尚未完成。不用一个百分比混淆图鉴美术、可玩规则、剧情和跨端交付。

## 2026-11-06 正式营救界面阶段

完成四十关和共用七关的一套经典单窗口精简：顶部合并信息、左侧敌方牌、三队直接选取与场景命令、事务编队、博士藏身、局部补给、菜单/来信/胜败/下一关。指南及等待、右栏、底栏、日志、正式设计入口和网页关卡下拉框已移除。新增鼠标实时落点，选队不自动展开大命令板。战斗模型、地图坐标和数值保持原实现，经典对线独立保留。

已经执行本阶段 Review、修复与定向复核；实际检查包含 Electron 来信/编队取消/藏身/出发、浏览器真实交互、多地图和较小窗口。没有用自动检查数量替代视觉结论，也没有宣称四十关逐关人工通关或安卓验证。详情及五类截图见[阶段记录](界面精简与阶段Review-20261106.md)。

后续设计已重新核实功能状态，以[双目标营救与证据运输](后续玩法与完整叙事设计-20261106.md)优先；未实施新玩法。用户新增授权在本地完成后同步 GitHub 源码；本轮不打包、不创建 PR/标签/Release、不变更更新清单。以下 11 月 5 日启动记录及历史验证结果保留为当时证据。

## 2026-11-05 本地启动开发

- 新增根目录 `Start-Electron.cmd`，`Start-Game.cmd` 与 `game/Start-Slice.cmd` 统一进入 Electron；`npm start`、`npm run dev` 同样启动桌面。网页预览改用 `npm run start:web`。
- 修复容器仅支持打包目录的问题：源码读取根目录 `game/`，打包布局继续读取 `desktop/game/`，使用本地 `pvz://game/` 协议，不依赖 HTTP 服务。
- 开发版单独使用 `ZombossRise-Dev` 用户数据目录，正式包保留 `ZombossRise`。旧浏览器地址和下载快照的历史存档不会自动迁移到开发档。
- 通过本机私有配置复用已安装的 Electron 43.7.5，仅使用运行库，不引入其他项目业务代码；运行库路径不加入源码仓库。打包工具目前记录的运行库与此开发运行库分开管理，之后构建时须明确选定版本。
- 保持沙箱、上下文隔离、默认游戏禁网和受限更新桥接；开发窗口允许开发工具，正式包继续禁用。
- Windows 原生窗口中实际核查了主菜单 → 开始冒险 → 序章漫画。并通过桌面入口 4 项定向检查、原生更新 18 项检查；未执行新一轮全量 Review、安卓设备测试或完整四十关人工通关。
- 没有重新打包、升级公开版本、推送、创建 PR、标签或 Release。
