# 地图站位、角色放大与排版修复

用户提供的夜间屋顶截图揭示了此前视觉抽查遗漏的偏差：背景瓦片仍按原图的弯曲透视和较宽列距显示，单位、墓碑及点击判定却使用规则十列网格。只检查角色彼此是否同排，无法证明它们与地面图案一致。

本轮修复当前营救玩法与共享地图预览，不修改战斗数值、地图可走格、存档或发布身份。未打包、推送或发布。

## 修复内容

1. **屋顶地面与判定对齐。** 日间、夜间屋顶使用原版瓦片图，通过逐列去除原图透视偏移，铺进实际五行十列区域；保留外围原版场景，屋脊标记对齐既有直射阻挡阈值。栅栏后的博士区域也延续同一地面行距；水域、地下补齐场外指挥区地面，避免博士像贴在墙面或背景蘑菇上。没有靠逐个移动角色去掩盖背景错误，也没有新增坡面物理。
2. **再次放大当前实战角色。** 常规植物由 1.02 增至 1.18，高仙人掌 0.87 → 1.02，倭瓜 1.13 → 1.30，地面僵尸 0.71 → 0.88，气球 0.59 → 0.72。场外向日葵、博士和护送标识同步调整。人物仍使用原来的逻辑脚点，花盆在此基础上抬高 22 像素。
3. **绘制、点击和遮挡一致。** 点击范围按实际显示的编队成员、帽子和气球高度生成。普通点击按前后遮挡选取，修复下行头部误选上一行脚点的问题；明确下达布阵或汇合指令时，脚圈仍可作为目标。实际浏览器点击相邻行重叠处，确认选择的是前方的队伍 3。同格木牌也避让墓碑、房门、栅栏和博士，最后用用户截图中的首行双队与第四行博士场景复核，木牌不再盖住第一段栅栏。
4. **倒地不再跳到队伍中心。** 保留倒下前的成员位置和朝向；幸存者使用原来的编队槽位，避免一名队员死亡后全队突然横移补位。此状态仅属于绘制缓存，不更改战斗模型。
5. **战场占满内容宽度。** 原侧栏说明移至编队与补给区之后。提前出发、暂停、重开及当前一步放在草坪上方；战前背景开战时收起，玩家可以重新展开，常规刷新不会强制关闭。顶部画布信息栏上移，为首行高角色留出空间。

统一逻辑区域仍为 x=180…980、y=172…652，格宽 80、行高 96。五行脚点依次为 252、348、444、540、636；屋顶、地面、桥面与地图输入使用同一套坐标。地面贴图变化不改变单位所在的行列。

- 角色放大保留植物、僵尸不显示血条的约定；墓碑和栅栏仍显示各自状态。
