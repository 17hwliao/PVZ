# 0.4.0之后的内容候选

这份清单在当前全量Review、五项确认问题修复和回归通过后整理。以下均为尚未实现的候选，不代表已发布或已批准开发。

| 候选内容包 | 可以包含什么 | 当前依据与收益 | 粗略成本 | 最小可验收切片 |
|---|---|---|---|---|
| A：第三章·小镇救援（优先） | 城镇外环、街区据点、幸存者转移；先救巨人再加入编组；承接宣传所证据，补开场信和Q版漫画 | 第二章已以小镇灯光收束，解救/卡组/漫画管线齐备；最直接增加主线可玩内容 | 中—高，估计 | 先做一场街区战、一个巨人囚室和战后解救；旧存档进入第三章，未救巨人不可选 |
| B：战术与挑战包 | 关前护具方案、一次性僵王支援、补给/电网/增援组合挑战；同一关不同阵容与资源限制 | 已有三种环境机制和五兵种，但养成和主动技能尚为空；提升复玩与战术选择 | 中，估计 | 一项有费用与冷却的支援能力、三个可重玩挑战；难度限制明确，不增加隐藏失败条件 |
| C：Z科技与终局叙事包 | 巨人之后的零件收集、机甲决战、后院胜利与梦醒、按和平/强攻/毁灭改变梦醒情绪；增加对白、漫画和音效 | 当前只有序章伏笔与两章故事，机甲与最终梦醒尚未实现；完成最初核心叙事 | 高，估计 | 先做一场机甲战和可跳过/回看的结尾演出；越狱开始即幻想的设定前后一致，分支不改变现实结局 |

三个候选可分期发布：先A增加主线，再视反馈选择B丰富战术，最后C收束故事。也可以只选其中一项。具体关数、兵种参数和发布时间须在选定后制定，当前不承诺日期或工期。

本次没有新建PR、标签、Release或自动发布工作流；已获授权的远端动作仅为将当前完整源码更新到指定PVZ仓库。PC和APK交付保持本地下载包，后续公开发布范围由用户决定。
