# 0.5.2 三种界面风格正式接入

用户选择三种设计全部采用。本版把三种设计作为可保存、可随时切换的界面风格接入正式游戏，默认经典木牌。

## 实际行为

主菜单“选项”以及战斗“菜单→设置与档案”都可选择经典木牌、僵族石刻、旧纸来信。分别保留原版欢迎木牌/卡通字、裂纹石牌/剪纸字、撕边信纸/艺黑字。选择即时生效并记录在现有版本2存档的uiTheme字段；旧存档与非法风格默认木牌，不增加兵种或改变关卡状态。

主菜单记录牌读取真实当前行动号及已解救人数；完整关卡名保留在无障碍名称与原生提示中。点击任一种记录牌都打开真实章节选择。保存成功只短暂提示“旅途已记下”；读写失败会持续提示，损坏存档不覆盖，风格只在当前窗口临时生效时明确标注“未保存”。

原版位图字体用于主菜单、标题、按钮与选择入口；详细正文使用随包的中文卡通字体。三套原版字形均有1514字符，新字由站酷快乐体补齐。资源与OFL许可随包，不依赖在线字体。字体单独加载，部分读取失败仍保留可读文字并允许正常开战。位图文字保留屏幕阅读器标签，键盘焦点仍可见。仅在相关界面内容或风格变化时重画文字，不在战斗每帧重建字体画布。

同时修正实际浏览器发现的来信标题浅字低对比，以及纸张外黑矩形：采用原版纸张遮罩与深色标题。对话类名/选中状态变化时同步重画文字颜色。Android补充font/ttf MIME，沿用现有沙箱、离线资源路径与应用签名。

## 验证范围

现有79项加新增5项，共84项行为检查通过；11个脚本语法与313个本地资源引用完整，42项原版未修改贴图哈希一致，三套4542个字形坐标有效。最后对对话类名观察与来信显示调整，重复核对5项风格检查、7项工具交互及资源检查。

新增检查覆盖三种风格保存重开、旧存档与非法值回退、战斗暂停时切换不耗资源、不重开关卡、真实记录牌与章节入口、损坏存档不覆盖与字体缺失后可正常开战。

实际桌面浏览器核对默认木牌、切换三种风格、重开后保留来信风格、真实序章/信件/选卡/开始行动，以及战斗设置中切换前后能量均为201。浏览器错误日志为空。没有重复完整七关人工体验；该轮不声称完成移动端视口核对、Windows原生窗口或Android设备测试。该轮为开发验证，未进行新的全量代码Review。
