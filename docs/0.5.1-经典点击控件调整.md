# 0.5.1 经典点击控件调整

范围：按用户反馈修正点击框的网页控件感，沿用经典素材，不改变战斗数值、关卡与剧情。

- 主菜单不再排列四条相同长按钮。直接使用原版冒险模式石牌及高亮、纸质图鉴及高亮、选项字图。开始/继续营救的动态状态显示在冒险石牌下方，图片中文字和无障碍名称保持对应。
- 通用按钮由重复拼接的左右端和中段，改为原版完整裂纹石牌，保留斜边、破口与按下图。暂停菜单区分较大的返回按钮和次级入口；章节石牌增加高度，锁定内容仍可阅读。
- 设置改为原版勾选框，补充声音和柔和转场的完整无障碍名称及开关状态。
- 战斗卡片选中用小箭头提示，取消荧光矩形描边；行入口取消矩形底色。键盘仍有文字下划线、原生高亮或卡片点线焦点。
- 修复实际查看时发现的样式优先级冲突：图鉴选中标签曾残留旧绿色背景并重复平铺新贴图，现完整重置背景；召唤入口的准备状态也不再恢复旧矩形底色。

8张新使用的原版图片未修改字节；原版素材来源清单现记录39项哈希。其他界面仍是为反向塔防独立实现的布局，并非原版EXE逐像素复刻。
