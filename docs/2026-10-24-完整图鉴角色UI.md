# 经典完整图鉴角色 UI · 2026-10-24

本阶段按经典原版完整图鉴制作 49 种植物与 26 种僵尸，包括尚未进入本游戏关卡的角色。新增 64 张独立透明立绘，另外 11 张从已认可的当前角色画风导出。植物保留严厉守卫的神态，僵尸使用整洁或修补过的服装，表现为有职业与生活的同胞。

阶段标识：`classic-full-almanac-20261024`。最低核对范围为75角色形象齐备、四种僵王样式保留经典巨型机甲、图鉴交互与存档隔离有效，以及新增界面实景可视。前三项已有素材和自动检查证据；最后一项在新增切换区上仍待浏览器恢复后核对，因此本阶段未标记为全部视觉验收通过。

## 使用入口与范围

主菜单「同胞与故事」→「植物与僵尸图鉴」，或直接打开 `game/almanac.html`。图鉴提供分类、名称／职责／英文 ID 搜索、大图、故事手记和前后翻页。植物使用经典木框与纸页，僵尸使用经典石框；相框、卡面及底图取自本地经典素材。

已进入前两章的六种植物、五种僵尸继续沿用当前战斗表现。图鉴按实际存档区分已解救、待解救和「尚未登场」，浏览不写存档。新增图鉴角色没有提前解锁，也没有新增召唤、攻击、受击或死亡机制；完整战斗动画仍属于后续角色接入工作。

## 素材与导出

- 每个角色单独制作与检查，不使用一张合集切出多个角色。
- `game/assets/almanac/`：75 张 512×512 透明 WebP，统一留白与底部基线；源 PNG 留在本地工作输出。
- `asset-manifest.json`：逐角色源图与运行图 SHA-256、实际轮廓边界。
- `provenance.json`：生成提示词、修订信息、参考来源和原版 UI 素材哈希。不含本地个人工作约定。
- `game/almanac-data.js`：完整图鉴、角色名称、职责和剧情描述，与战斗配置分开管理。

## 视觉核对

检查角色物种轮廓、头数、喷口数、装备完整性和透明边缘；在游戏真实图鉴界面检查卡片、选中框、大图相框、文字、翻页和滚动。修正了西瓜多出的豌豆口、机枪多出的炮管、三叶草错误长喷口、地刺王过高轮廓，以及旧仙人掌在图鉴导出时底部平截等问题。玉米加农炮按经典横向车架与木轮补充识别结构。

本阶段仅开发与浏览器视觉核对，未打包 PC／APK，未推送、创建 PR 或发布。自动检查结果与最终视觉证据随完成记录补充。

## 续作：僵王文化主题样式

在同一位僵王博士详情内提供四种造型切换，不增加经典图鉴的角色数：

| 造型 | 主要美术特征 |
| --- | --- |
| 经典巨型机甲 | 保留此前版本，巨大僵尸头躯干、顶部博士驾驶舱、厚重机械双臂与双脚 |
| 青铜机关 | 中式青铜云纹、朱漆梁架、榫卯和暖金铆钉 |
| 砂金王朝 | 古埃及砂岩色装甲、青金条带和旧金镶边 |
| 蒸汽工坊 | 维多利亚工坊的黄铜、铸铁、铜管、活塞和压力表 |

四者共享原版巨型机甲的战斗设计方向：厚重砸击、冰火球和投放同胞。当前交付是完整人物立绘与可切换图鉴 UI；本游戏尚未实现僵王战斗关卡，不把文字说明算作已完成的战斗机制。图鉴明确显示此状态。切换不写存档，不改变前两章的伤害、解锁和编组。

三个新增样式通过内置 image_gen 单独生成，源图目视检查了驾驶员、手脚、装备及完整轮廓；透明边缘最大 alpha 为 1／0／1，没有可见截边。运行图统一导出为 512×512 WebP，提示词与哈希见 `assets/almanac/boss-styles-provenance.json`。直接入口 `game/almanac.html#boss`。
