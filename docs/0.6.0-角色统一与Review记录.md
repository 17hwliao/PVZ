# 0.6.0 角色统一、连续帧修复与整体 Review

日期：2026-10-23。范围：用户要求统一剩余植物与僵尸、适配攻击受击、修复植物下半身消失和面部重影；整体Review、修复，并重新打包PC和安卓。沿用当前main和此前已完成但尚未打包的剧情互动，不新建远端分支、PR、标签或Release。

## 实现范围

六种植物：豌豆、寒冰、坚果、向日葵、仙人掌、大嘴花。五种可玩僵尸：普通、路障、铁桶、气球、矿工。新增9张透明PNG图集；普通、路障、铁桶共用文明同胞脸，另有气球信使、矿工救援工。表情覆盖常态、攻击用力、受击；坚果使用三级破损；大嘴花分上下颌、口腔和舌头。衣装、护具、主要骨骼和工具保留经典资产，未声称重画整套逐帧动画。僵王能量标识仍保留经典形象。

保留三套界面风格、五碑规则、每碑一次500能量、进门或两路小车获胜、胜后解救、七关与两条分支。此前本地试绘中的饭盒、囚室接应、造谣档案及墓碑列场景纳入本次版本。

## Review 方法与覆盖

使用light-code-review执行一轮整体审查，覆盖当前运行代码、前一轮未暂存改动、新增文件、角色/动画数据及加载调用链；检查战斗引擎、卡组/救援/存档、剧情/漫画、主菜单/图鉴/键盘/暂停、三套字体与界面、资源回退，以及Electron、Android和本地构建脚本。检查原版资源哈希、所有动画绑定、图集裁区和七关连续交互。纯生成数据通过结构与引用检查，并结合角色真实渲染检查；没有把自动测试等同于整机体验。

## 验证与限制

99项行为、交互与连续帧检查通过，11个JS文件语法检查、325个本地资源引用、原版UI源图哈希及字体图集边界检查通过。七关连续推进、两条分支、救援解锁、两路小车、墓碑一次奖励、旧存档与暂停恢复均沿用实际引擎检查。新增连续帧检查直接执行生产渲染器，检查攻击/受击/爆裂/出土/死亡及缺图回退；未仅凭静态截图判定动画修复。

使用生产渲染器和真实Canvas绘制角色常态、攻击、受伤、死亡对照。桌面浏览器核对植物攻击、图鉴和新面孔；截图保存在工作区outputs。PC原生窗口、Android实机、窄屏和旧APK覆盖升级未在本轮验证。最终包的签名、版本、逐文件一致性和SHA256以工作区独立构建校验清单为准。
