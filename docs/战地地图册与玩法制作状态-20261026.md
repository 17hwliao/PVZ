预览沿用当前五行十列。原版泳池是六行，但本轮只重映射原版水面到规划水行，没有声称已实现经典六行。水路的最后一列以原版石径画出干燥岸边，桥面由原版横木纹理铺平；地下采用蘑菇花园与裸土作色彩和脚点预览，正式洞壁、支撑柱和推车尚缺。

路线草图使用各地图自己的墙、缺口、桥位、按列换行通道与地标。路线检查要求所有任务点在不出边界、不进入末列、不走非桥水格的条件下可达。该检查证明有路，不证明已实现运输或难度合适。

## 十二类玩法

营救护送、双点交接、取证运输、有限反扑、搬运开桥、分批撤离、水面打捞、驳船护送、信标修复、迷雾侦察、吊篮接力、经典巨大僵王决战。

公共底线保持：三队各最多三名；60秒准备可提前出发；植物500初始阳光加五株免费场外经济向日葵。五株位于原小车位置，无敌、不占格不挡门、不需要支架、不计战斗植物上限；四十关场内上限为3—7株，来自此前8—12总量扣除五株基础经济，保留火力密度。准备阶段付费种植免冷却限制，提前出发承接剩余冷却；植物每格至少3秒慢速换行并保留各自攻击身份，射手弹丸不全图追踪；五段600耐久栅栏独立受击；博士由玩家指定藏身行，人机不读取隐藏信息，博士按10次命中记录。

地图册是独立预览：动画只推进展示时钟，不运行战斗、生产阳光或判定胜负，不写入冒险存档。旧七关试玩与四十关长线是独立实际游戏入口，原冒险继续保留。四十关采用独立逐关进度，十种单位先救后编组；全关试演不写正式进度。其余十一类任务不提供伪装成完成品的实战，矿工遁地、扶梯架梯等单位特技也未全部实现。

## 战役的单一因果线

囚室与门外的声音 → 饭盒、灯房与粮仓 → 工坊、药袋和通风图 → 登记员作证 → 接回保管副本的人 → 退件和投递簿 → 口岸与石桥 → 巨人、小鬼和货场住户 → 最后一批撤离 → 泵站打捞护板 → 运河驳船运件 → 工坊恢复供电 → 屋顶吊篮与散热器 → 夜间校准信标、试车 → 雾中先救平民 → 切断后院补给 → 经典巨大机甲决战 → 胜利、梦醒与循环。

登记员2-3获救后留在灯房，不在2-4重复被囚；2-4接的是保管副本的两位同胞。阿铆与老周不同，灯房等老周的小鬼与货场获救的小鬼也不同。巨人先是搬运者，小鬼是独立同胞。第四章先解释能力来源和练习，第五章才以经典巨大僵王作为正式决战默认版本；文化造型共享机制。

所有终章真相、三个尾声节点与逐关伏笔默认隐藏。只有显式勾选剧透才展示，关闭时清掉正在显示的结局正文并回到安全节点。底层设计仍坚持：抓捕、电刑真实；从击倒守卫、同族营救越狱起全部是幻想，现实从未逃离囚室，分支只改变体验和梦醒情绪。

完整节点、角色生命周期和机甲预兆见[完整战役与地图串联](完整战役与地图串联-20261025.md)。水路与屋顶的细节见[水路与屋顶地图设计](水路与屋顶地图设计-20261025.md)，其余见[夜晚与迷雾地图设计](夜晚与迷雾地图设计-20261025.md)。

## 验证与接续

当前地形机制、四十关与场外经济列的测试范围及结果详见[地形机制与四十关实装](地形机制与四十关实装-20261026.md)。旧地图册轮次的完整日志与专项输出作为历史证据保留，不把历史检查数量当作当前全部执行结果。

地图册预览阶段曾在实际浏览器逐幅检查八种场地，并检查桌面战役目录、375px内容宽度的窄屏场地与战役、模式状态、剧透展开／收起及正文清理，修复目录木牌压缩重叠、桥面与岸边。那些截图是当轮实际页面，不能覆盖之后新增的四十关入口。当前浏览器使用被Work设置禁用；最新机制与布局使用实际模型、生产渲染器画布输出检查，画布导出不是整页截图，最新整页操作和窄屏体验仍有缺口。

这些核对不等于原生PC／Android实机、真人难度体验、所有角色动作或整仓代码Review已经完成。本阶段仍在开发，不自动追加发布。

之后可在已经接入的水域、迷雾和屋顶底座上，继续制作双目标跟随／交接／逐人结算，再扩展运输和机甲。四十关当前仍为单目标护送，不因地图与阵容增多就冒称十二类任务全部完成。
