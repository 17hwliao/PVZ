# 0.8.0 冒险指引与交付

本阶段范围：主冒险进入八境四十关；现有重绘序章接首关来信和首次指引；完整操作、地图、关卡与设计内容可回看；保留经典对线及原存档；完成阶段 Review、修复、测试后发布可更新的 PC 和 Android 版本。

验收标准：
1. 首次从主菜单开始冒险能走完漫画、来信、指引并下达真实战斗命令，跳过和回看不破坏进度。
2. 指南覆盖三队、合并分开、回血补员、十次命中、敌方种植、八境四十关和未实装设计，规则与生产数据一致。
3. 阅读、暂停、后台、更新面板和自动接续的状态互不覆盖；旧存档和旧模式继续可用。
4. 阶段 Review 问题修复并定向复核；自动测试与浏览器视觉证据各自记录。
5. 版本与构建号递增，PC/APK 资源一致、原 Android 签名、更新清单摘要匹配；只发布一个用户可识别的稳定版本到原仓库。

授权来自本次用户“开发后 Review、修复测试、打包可更新下一版本上传 GitHub”。沿用 main，无相关已有 PR，无 GitHub 工作流自动副作用。发布前核实最新稳定版本与工件身份。

## 构建与更新

正式包从已提交源码快照构建，排除 Windows 工作区换行转换造成的源码/成品字节差异。555份游戏文件在源码快照、PC目录与签名APK内逐字节一致；桌面主进程、preload与更新器均包含。源码快照又执行指南8项、更新UI15项及资源检查通过。完整构建清单见同目录视觉证据中的 `build-verification.json`。

- Windows x64：`ZombossRise-0.8.0-windows-x64.zip`，完整解压后运行 `ZombossRise/ZombossRise.exe`。
- Android：`ZombossRise-0.8.0-android.apk`，包名 `cn.zombossrise.game`，版本0.8.0/800，minSdk26/targetSdk36；v2/v3签名和16KB对齐检查通过，签名与0.7.0一致。
- 源码：`ZombossRise-0.8.0-source.zip`，由发行对应提交直接生成，不含本地工作目录、node_modules、运行库、密钥和密码。

沿用稳定版固定 `releases/latest/download/update-manifest.json` 入口。0.7.0及以后版本可在“检查更新”看到递增构建并打开平台下载；安装仍由玩家确认。Windows替换完整程序目录，保留AppData内ZombossRise数据；Android使用同签名覆盖安装，保留应用数据。游戏原存档键、原生来源和包身份均未改变。

验证边界：Windows便携包未作发行者Authenticode签名；本次浏览器视觉和真实命令验证不等同于PC成品窗口验收。Android未做本次实机安装/覆盖升级，也没有假称安装后再次升级已验证。正式发布只包含本次一个0.8.0稳定版；内部检查包不上传。
