# 0.7.0：PC、Android与版本检查

本版统一版本号为0.7.0、构建号700，包含旧冒险、七关小队营救、八地图四十关营救、完整经典角色图鉴及地图设计册。机甲终战等标注为设计的内容仍未实装。

## 下载与运行

- Windows x64：下载`ZombossRise-0.7.0-windows-x64.zip`，完整解压后运行`ZombossRise/ZombossRise.exe`。它是便携目录，必须保留旁边的资源及运行库。
- Android 8.0以上：下载`ZombossRise-0.7.0-android.apk`，由系统确认安装。沿用`cn.zombossrise.game`包名和原签名，versionCode由600升至700。
- 源码：`ZombossRise-0.7.0-source-final.zip`，不含运行库、node_modules、私钥或密码。

发布入口为[GitHub Releases](https://github.com/17hwliao/PVZ/releases/latest)。首次加入版本检查的版本是0.7.0；此前离线版本需手动下载一次。

## 更新流程

主菜单及两处营救页面提供“检查更新”。游戏内容离线运行，只有主动检查版本时由原生层联网。原生层请求固定地址：

`https://github.com/17hwliao/PVZ/releases/latest/download/update-manifest.json`

检查器验证清单版本、稳定通道、固定仓库与标签地址、平台资产名、文件大小及SHA256格式，并比较数字版本与构建号。远端版本不得低于本地，构建号必须增加才提示新版；网络失败显示失败并可重试，不当成“已是最新”。较新版本随后可继续请求同一固定入口。

发现新版后，玩家点击“下载PC新版／下载安卓新版”，由外部浏览器下载对应的已验证地址。当前实现不在后台替换运行程序，也不静默安装APK；清单摘要用于文件核验，不能把“打开下载地址”描述成“已验证下载字节或安装成功”。

Windows沿用AppData下`ZombossRise`数据目录及`pvz://game`本地源；Android沿用包名、签名及`appassets.androidplatform.net`源。更新应覆盖原安装／替换程序目录，勿删除应用数据。旧浏览器HTTP试玩与原生应用存档是不同来源，不会自动迁移。

## 下次发版

1. 修改`release/version.json`中的数字版本及递增构建号，运行`node tools/sync-version.cjs`同步根包、桌面、Android Manifest和网页显示。
2. 运行自动检查，用原签名生成APK及完整PC目录。构建脚本会拒绝版本不一致、缺少输入或覆盖已有构建目录。
3. 将两个平台包放入独立发布目录，文件名符合上述版本规则；运行`node tools/make-release-manifest.cjs <目录>`生成实际字节对应的更新清单和校验和。
4. 上传平台工件及清单，核对摘要后公开稳定Release。固定latest入口指向最新稳定发行。

私钥与密码单独保管，不能上传仓库或加入任何压缩包。Windows当前为未作发行者代码签名的便携包；Android使用既有私钥签名。

## 验证边界

构建、APK签名、包内版本与跨端资源一致性检查记录随本次交付提供。生产模块及DOM自动检查不等同于Windows真实窗口体验、Android实机安装升级或安装后获取下一真实版本，这些不可据此宣称通过。

实现参考：[Electron隔离桥](https://www.electronjs.org/docs/latest/tutorial/context-isolation)、[Android WebView](https://developer.android.com/develop/ui/views/layout/webapps/webview)、[GitHub Release API](https://docs.github.com/en/rest/releases/releases)。


本次实际构建核验：551份游戏文件在源码工作树、PC包与签名APK内逐字节一致；PC三个原生模块均包含；APK实际包名cn.zombossrise.game、版本0.7.0/700、minSdk26/targetSdk36，原4096位RSA证书摘要与0.6.0一致，v2/v3与16KB对齐核验通过。Node检查32个脚本共300项通过，35份网页JS语法有效、549个本地引用无缺失。Android检查器另有50条真实Java行为断言与10条桥接静态契约检查通过。

Android检查器开发测试单独运行`npm run test:android-updater`，需要本地JDK与android-json测试jar；可以通过`UPDATER_TEST_JDK`、`ANDROID_JSON_JAR`指定。该工具不会自行下载依赖，默认Node游戏测试不依赖本机Android工具链。

自动审批检查拒绝了启动Electron后台联网验证进程，未尝试绕过。保留Windows原生联网与真实窗口、Android实机安装升级、跨版本实际安装后的继续更新验证缺口；发布成功和模块测试不替代这些证据。
