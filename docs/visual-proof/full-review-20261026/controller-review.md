## 已确认问题与最小修复

**UI-R1（已修复并定向验证）：结果页打开更新面板后仍会自动接续。**

旧 `frame` 的倒计时分支检查页面可见、读信和未来册状态，却不检查 `scene.paused`。触发路径为护送成功→收好回信→打开更新面板。虽然更新事件令场景暂停，8 秒后仍会重置下一局；这也可能让更新面板后的剧情与关卡错位。

修复是在自动接续分支加入 `!scene.paused`。定向复核还覆盖末关与失败：结果页原暂停键始终禁用，如果只冻结倒计时，末关没有“下一关”就无法恢复。现在仅在结果页已经暂停、启用自动接续、尚未展示后续册时，既有木牌启用为“继续接续”；用户明确点击后才恢复倒计时。中途胜利可继续下一关，末关翻开设计册，失败重试本关。未改胜负与存档规则。

本分工未确认第二项剧情或进度卡壳；不是对所有路线和设备无缺陷的保证。

## UI 实现与边界

- 草坪下沿独立文档流木卡槽，使用现有 `SeedBank`、`SunBank`、`SeedPacket_Larger` 及图鉴角色素材，不覆盖草坪，不增加植物血条。
- 突出植物阳光、场内数量及上限；场外 5 株免费无敌向日葵不计场内数量。准备期可免 CD，但实际落种冷却仍写明会带入开战。
- 每关按实际卡组显示费用、模型剩余秒数及遮罩进度；区分缺阳光、冷却、上限、已就绪。水面睡莲与屋顶花盆按实际 25 阳光及共享卡冷却展示。支架与咖啡豆不受攻击植物上限误禁用。
- 卡槽是敌方人机情报，不提供玩家落种。卡片就绪仍需人机选择合法位置，咖啡豆还需睡眠蘑菇；这些边界有显式文案。
- 横向卡组窄屏滚动且可聚焦，不创建遮住战场的浮动工具栏。
