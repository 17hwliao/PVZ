# 八地图营救兵种与数值梯度

本表服务独立八地图长线营救模式，不改旧冒险 `engine.js` 的五种 `UNITS`。数据入口是 [terrain-unit-data.js](../game/terrain-unit-data.js)，顺序与 [terrain-campaign-data.js](../game/terrain-campaign-data.js) 的营救关一致。营救本关只能用此前已成功接回的单位，新身份在返程结算后才开放，不能借用尚在囚室中的能力。

普通、路障、铁桶、气球的六项基础参数保持与旧单位一致。矿工在本轮调整为175物资、320耐久、24速度、60攻击的快速轻装攻坚者，尚未获得遁地能力，不再为未实现技能额外付出低耐久代价。新单位没有同时获得更便宜、更快、更耐打、更高伤害：纱门专精直射却降低常规耐久与伤害；水生身份为通路付出成本；扶梯伤害高但全队行军被15速度限制；橄榄球能快速重装接应，但一名需要275物资，比普通五人总价还高，且三人编组不能靠堆人数抵消成本。

## 身份和反制

| 单位 | 最小身份契约 | 主要限制与反制 |
|---|---|---|
| 普通 | 最便宜的占点、开门、接应与补位 | 耐久低，需要换班；保持伤员返程而非反复送死 |
| 路障 | 在相同近战伤害下，多一层基础护具 | 速度比普通低，冰豌豆减速照常生效，不能挡下吞食和压砸 |
| 纱门 | `projectileReduction:0.35`，前排承受正面同行豌豆/冰豌豆等直射时减少35%命中伤害 | 近战、倭瓜、吞食、抛射和地形不因此减伤；寒冰控制仍生效，侧后方不免费保护 |
| 铁桶 | 较高总耐久保护危险返程 | 更慢、单物资攻击量低，经典吞食与倭瓜不因厚桶失效 |
| 游泳圈 | `waterMove`，获得合法水域通行 | 陆上耐久效率不及路障；混编普通成员时不能把全队当游泳队，更不能带地面护送对象瞬移过水 |
| 潜水 | 水中未靠近攻击时减伤35%；距离目标0.8格内或正在攻击时露头恢复正常受击 | 陆上只有270耐久；水中也非无敌，近身仍受原版植物身份克制 |
| 气球 | 空中侦察与部分越障 | 180耐久，仙人掌刺破、三叶草对空预兆与降落状态必须清楚；不能替地面目标完成护送 |
| 矿工 | 320耐久、24速度与60攻击的快速轻装攻坚 | 175成本、护具仍薄于路障；`burrowImplemented:false`，当前没有遁地通行，不允许传送证人或无预兆出现在目标背后 |
| 扶梯 | 较高单次攻击量、可识别梯具外形 | 195成本、15速度；`climbImplemented:false`，当前目录不表示已实现架梯跨坚果、放梯和遗留梯具 |
| 橄榄球 | 26速度、68攻击的高成本快速重装 | 275成本、16秒节奏元数据；`bonusImplemented:false`，不额外叠加冲锋暴击、无敌或撞飞。寒冰、吞食与倭瓜依旧构成应对 |

纱门采用全程正面弹丸减伤的最小版，不假称完整独立盾牌生命系统。未来若实现盾破后失去减伤，应重新核算其优势，而非在相同数值下悄然削弱身份。潜水减伤必须在水格、未露头、未攻击条件同时成立才应用；不得仅因拥有潜水头像就全场常驻减伤。

## 每100物资得到什么

下表是静态比较，不是模拟胜率，也不是DPS。耐久/物资是 `hp ÷ cost × 100`；攻击量/物资是 `damage ÷ cost × 100`，只有攻击频率相同才可进一步比较持续输出。

| 单位 | 常规耐久/100物资 | 单次攻击量/100物资 | 额外购买的能力 |
|---|---:|---:|---|
| 普通 | 420.0 | 92.0 | 最低补位门槛 |
| 路障 | 430.0 | 46.0 | 前排存活时间 |
| 纱门 | 345.5 | 38.2 | 正面直射下等效531.5耐久/100物资 |
| 铁桶 | 433.3 | 30.7 | 单槽较厚耐久，适合三人上限 |
| 游泳圈 | 258.3 | 35.0 | 原本不可走水格的通路 |
| 潜水 | 174.2 | 28.4 | 水中未露头时等效268.0耐久/100物资 |
| 气球 | 144.0 | 36.8 | 有反制的空中信息和通路 |
| 矿工 | 182.9 | 34.3 | 轻装攻坚的较快行军与单槽攻击 |
| 扶梯 | 246.2 | 37.9 | 单槽较高攻击，牺牲全队速度 |
| 橄榄球 | 269.1 | 24.7 | 单槽快速重装与后段接应 |

例：150物资可以补三名普通或一名铁桶。三普通合计630耐久、138攻击，但占满一队；铁桶650耐久、46攻击，却只占一槽，可留两槽给其他身份。不是铁桶全面优于普通，也不是三普通永远更好。普通队在便宜修整、分路驻守、接手护送时始终有明确价值。

纱门面对纯直射的等效耐久为 `380 ÷ 0.65 ≈ 584.6`，每100物资约531.5；面对近身仍只有380。潜水在水中未露头为 `270 ÷ 0.65 ≈ 415.4`，每100物资约268.0，露头立即回到270。减少伤害不等于减少减速、免吞食或免压砸。

## 编组与地图梯度

- 每队最多三名，混编行军速度由存活成员最低地面速度约束，快成员不能拖着慢成员瞬移。队伍能力由全体通行条件决定：一名游泳圈不能让两名普通一起游水，一名气球不能把地面目标带到水对岸。
- 草坪学习三队接力；夜晚增加有预兆的近程与直射选择；地下让慢前排保护整备与返程；泳池再引入可选水路，固定桥仍保证无新能力可达。
- 迷雾增加观察与对空，运河增加侧路与水岸选择；屋顶让慢攻坚队与机动队分工；夜屋顶考验综合接应。关卡压力来自预算、落点和原版植物组合，不机械每关提高敌方伤害。
- 新单位获救关不提供该单位免费助战。获救后第一次使用时说明身份、限制和实际可走格，避免能力只藏在文档。
- 具名获救者和普通编组成成员区分；不把单位阵亡自动写成具名人物永久死亡，也不让已确认死亡的人下一关照常来信。

## 头像、动作和实现边界

全部十种 `portrait` 逐一与当前 `almanac-data.js` 的原版图鉴记录及本地文件核对，均使用实际存在的 `assets/almanac/*.webp`。`portraitOf`、`actorOf` 对未知ID回退普通，避免选卡出现破图或未定义动作。

生产动作仍只映射现有 `zombie`、`balloon`、`digger` 三种骨架；`visualType` 只用已有 normal/cone/bucket/balloon/digger。纱门、泳圈、潜水、扶梯、橄榄球的专属携具和轮廓应由营救渲染层单独适配，不把普通身体加原版头像宣称为完整原版动作。此次目录不改变旧冒险角色的动画、资源或数值。

目录中的水行、减伤、露头、飞行与出土需要营救模型分别接入，不能由字段存在推断实现。下面的模型通关核查确认一组合法策略能完成40关，不代表所有特殊技能和动作均通过视觉核验，也不把静态等效耐久表写成已经平衡。

## 最终共享护送与守卫规则的40关覆盖

主线程随后收紧接应与跟随通路：交接需要真实短路径，不能隔着碑和篱墙绑定；已经开始的合法跟随路径能继续绕行，不会因暂时超过欧距而冻结。首次收拢发现L4-1的相邻水上射手仍可跨行永久封门，因此守门与取碑现在判断实际交互队所在行的清醒敌对守卫，并允许另一支未受压制的邻近队完成交互；水上射手仍保留在原行正常攻击，没有被删除，也未提前赠送游泳单位。
