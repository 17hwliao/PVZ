# 八地图四十关与营救成长

2026-10-26 · 独立营救长线数据 `PVZ_TERRAIN_CAMPAIGN` · [数据源](../game/terrain-campaign-data.js)

本长线已通过 `terrain-campaign-setup.js` 接入独立实战入口 `terrain-campaign.html`：八类地图各五关，共四十关。顺序为草坪、夜晚、地下、泳池、迷雾、水渠、屋顶、夜间屋顶。每一关使用**单人开门、实际跟随、护送回营**作为底座；三队调遣、补给碑与各关植物组合改变战术。水域通行、支撑层、蘑菇睡眠、迷雾与屋顶弹道已有模型规则，不再只是主题样稿。“修船”“搬货”“巨大机甲”仍不属于这四十关已实现的任务。

这是独立长线，不覆盖现有七关的身份、叙事进度或存档。四十名获救者均有独立名字，旧版阿朴、老周、登记员等不会重新被囚一次；旧七关和原 26 节点战役仍保留。本文记录已接入的模型范围、数据核对及自动检查，不代表四十关已经由真人逐关通关，也不代表全部关卡的难度和动作已完成视觉验收。

## 故事怎样连续走完

乔治从逃生通道进入草坪，首先只想让大家有一碗热饭。阿芦的饭、青禾的地址和小楮的原始收据说明，所谓吃脑子的证据由普通口粮登记改写而来。夜班簿帮助追查谁拿走了原件；夜间抄写员垣记承认自己曾参与重抄，不把获救当作免罪。

重写稿的物资编号通向地下工坊。扳手、药包、炉桶和通风图都被改成战争证据，而这些东西首先是住处能关门、伤员能用药、大家能洗热水澡的条件。地下水管又接向市政蓄水池，量水员、游泳接应者和潜水检修者的生活因果先于兵种能力出现。

泵站原账寄到低洼邮路却被退回。迷雾五关逐渐收齐寄件联、路标与两版稿纸，队伍才知道篡改发生在下游运河登记所。运河的缆绳、闸册和检修地道不是突然新增的战争舞台，而是同一条物资与邮件交通线。

卸货坡的清单指向屋顶维修竖井。送药人、盆栽寄存者和扶梯工证明，高处生活并不等于窥探住户；护板和散热器的本来用途又让乔治想到，用机器保护人而非把人当武器。夜间屋顶完成最后的接应名单与安全记录，四十关停在“开始准备经典巨大机甲”的动机处。冰火弹、踩压、机甲投放与最终梦醒属于之后的正式篇章，未提前塞入本长线实战，也未提前揭晓幻想真相。

`availableUnits` 只包含**严格早于当前关卡**已经营救到的种类。待救兵种不会出现在自己这一关的可用列表；获救只在真实成功返回后解锁，失败、查看信件或直接选中后关不能提前领到。玩家在同一关重试时也不能重复获取额外奖励。当前重玩早期关卡仍采用那一关的历史兵种范围，不自动把后期阵容带回教学关。

`terrain-progress.js` 使用独立键 `pvz-terrain-campaign-v1` 保存已完成关卡，默认只开放连续完成后的下一关。页面只在真实模型状态为 `won` 时登记完成，直接地址和选择框都会被进度限制。`trial=1` 是全关试演入口，用于查看指定阶段的阵容和地图，不向正式长线存档写入营救结果。保存失败时本次会话仍可继续，但界面提示刷新后可能回退。

成长不只是每张卡的生命值更大。前期增加护具和盾牌，中段增加水路与空路，后段增加地面机动、慢速攻坚和高速重装。矿工遁地、扶梯架梯、橄榄球额外冲撞仍未实现；当前对应人物先以各自成本、耐久、速度和攻击进入编组，不能据此宣称特殊能力完成。最终的橄榄球队员在整体接应能力上更强，但不能让所有早期单位失去低成本和补员价值。水上专精也不能被表述为对所有陆地攻击全面升级。

## 五关为什么不只是换标题

每种地图保留同一组固定桥、缺口与烟囱，防止新关随机毁掉已知路网。五关分别改变房门行、三座补给碑所在行与距离、可用兵种、守军卡组和预算压力。同一地图五关的房门／补给布局签名全部不同；三座碑始终分布在三条不同行，玩家不能在同一格顺手拿完。

每关固定前进接应碑、整备碑和口粮碑各一座；既有接应与修补规则复用。变位只从合法地面或固定桥格选点，不把补给直接摆在不可站立的水面。普通地面队在未解锁气球、潜水、矿工或扶梯时，也能经过固定路径接到目标再回来；新能力提供选择，不作为解救自己的唯一钥匙。

植物卡组随区域变化：草坪教豌豆、坚果、倭瓜；夜晚引入小喷菇、阳光菇与大喷菇；地下组合冰射、吞食和范围喷雾；水域使用岸线布防；迷雾增加路灯花和三叶草；高处组合咖啡豆与日间睡眠蘑菇；最终夜间屋顶汇合前面学过的威胁。睡莲与花盆属于支撑层，不放进会攻击的防线卡组，也不被当作召唤新敌人的按钮。

所有关植物初始 500 阳光保持不变。按本次用户明确的规则，五株开局向日葵免费配置在**战场外侧、原小车位置的独立经济列**，不占棋盘格、不挡房门与队伍通路，不会被攻击或移入战场，也不计入战斗植物上限。这五株是稳定的基础经济，不以击杀它们形成断粮策略；它们无需在泳池或屋顶战场上另配睡莲／花盆。场外经济列由专门状态与绘制层管理，不应再作为场内可攻击 `plants` 的五个开局成员。

场内后续部署才检查地形：非桥水格先付费种 25 阳光睡莲，屋顶先付费种 25 阳光花盆，再付费种本体；底座有独立冷却和耐久。准备阶段 60 秒可提前结束，种植免冷却与进入战斗后的剩余冷却衔接沿用现有约定。当前接入层将此前 8—12 株总量扣除五株基础经济，得到 3—7 株场内上限，以保留火力密度；场外五株经济向日葵不占此上限。僵尸起始物资从 150 缓增，`pressureTier` 从 1 到 8。独立出发编组预算从 450 递增到 1045，补员另付本场物资；这些参数尚不能证明四十关难度均衡。

## 已做的数据核对与边界

低成本核对已确认四十关、八图各五关、四十位独立获救者、十种招募和连续 `nextId`，每关三段信、两句对话与两段营地回应。招募时间与可用列表逐项核对，无“尚在门里却先编入队伍”的情况。

使用独立 BFS 按同列联络道、固定桥、水面和实体障碍核查：从三队起点及营地中心共四个起点，分别能走到房门与三座碑的合法相邻格，共 640 项普通地面可达检查通过。全部检查把待救新能力排除在路径要求之外。

场外经济列调整前曾运行 `tests/test-terrain-mechanics.cjs`，17 项检查通过，覆盖真实模型地形寻路、花盆／睡莲付费与损坏、蘑菇睡眠与咖啡、阳光菇成长、地下移动、迷雾观测与三叶草、水生混编、屋脊直射与抛射、阵容预算、进度隔离及页面锁关。其中旧“开局五株有场内支撑”契约已被本次场外经济列规则取代，不能把那项历史结果当作新规则已经验收；新规则需以更新后的模型与针对性结果为准。页面测试中的胜利触发用于核对解锁衔接，未把它当作自动打完或真人通关四十关的证据。

上述结果区分已接入规则、静态可达性和实际体验，不替代四十关逐关难度、全部动作自然度与遮挡的视觉检查。巨大机甲保持后续正式版本，本长线末尾没有自动进入未实现战斗。此次不打包、不推送、不发布。
