# 单窗口游戏布局 · 2026-11-01

> 历史阶段记录。正式营救布局及操作已于 2026-11-06 进一步精简，以[最新阶段记录](界面精简与阶段Review-20261106.md)为准；旧截图保留为当时证据。

主冒险和七关小队营救已从长网页改为固定游戏画框。原有控制器、DOM ID、存档和战斗规则保持关联，不复制战斗模型。

## 操作位置

- 上方木牌：关卡、提前出发、暂停、重新部署、菜单。
- 中央：完整草坪；左边为植物阳光与冷却卡槽。
- 下方：三队与博士选择、行军命令、即时指令反馈。
- 指挥台分页：编队、墓碑补给与转队、情报与记录。长内容仅在册页内部滚动，整页不再滚动。
- 菜单：指南、来信、窗口内地图说明、返回主菜单、更新和全屏入口。打开菜单暂停，返回后由玩家继续。
- 开战时自动切到补给，之后手动翻页不会被状态刷新抢回；新一轮准备恢复编队。
- 结算位于同一游戏画框内；自动接续、回信与下一关仍由原控制器处理。

原主菜单与经典对线也改为适配窗口的完整画框，版本和保存信息收进底部木边。“故事漫画”通过游戏内故事档案打开。

## 已发现并修复

1. 固定画框后，底部按钮和反馈文字重叠：移除重复小标题，分配独立反馈行。
2. 画框整体缩放时，同格队伍牌尺寸被二次折算：使用画布本地宽度计算布局，鼠标命中仍使用屏幕矩形。
3. 原手机样式把关卡选择与菜单挤出标题栏：清除继承的整行宽度和顺序。
4. 短横屏按桌面比例缩小导致字体过小：改为按可用高度排列战场与指挥台，保留实际字号。
5. 七关入口没有八境地形数据：菜单显示本入口实际七关同胞册；四十关入口显示八境地图，避免空白地图册。
