## 优先切片一：双目标营救与交接

建议入口：L2-5 后的一张夜间插章《借来的餐桌》。两个相邻囚室里分别关着做饭的人和负责分食的人；两人都与第一幕的饭盒线有关。选卡仍是三队、每队三人，六十秒准备和现有物资、补给、种植规则不变。

### 一局流程和状态

1. 来信交代两个姓名。场景只增加 A/B 两扇门和营地两个抵达标记，不增加目标侧栏。
2. 门沿用现有关卡的补给要求与驻留开门时间，各自检查实际靠近、停稳且可交互的地面队。多队同时满足时按稳定队伍 ID 选取，不凭渲染顺序。
3. 每名目标分别经历：被关押 → 已释放 → 跟随/等待 → 已抵达。单独保存 ID、坐标和护送队，不共用一个 follower。
4. 最小版本每队同时接应一人，护送者不计入三名作战成员槽。两个目标不能被同一队重叠“吸走”。
5. 实际进入营地才记录该人的抵达；抵达 ID 去重。首人回营只亮起一个营地标记，不能提前弹胜利或写全关完成。
6. 两人均实际抵达后统一结算一次，回信根据先后顺序和伤亡写简短变化。

目标数据从当前单一 `goal/follower` 扩成独立目标集合和护送集合，结算消费统一的目标账本。旧单目标关卡用适配层形成长度为一的集合，先保证旧四十关行为不变，再启用本切片。

### 交接怎样操作

双方队伍停稳，距离不超过一格且之间存在连续合法陆路时，点击被护送者附近的小木牌“交接”，再选相邻的接手队。没有空护送名额、隔墙、隔水或双方还在移动时不给接手资格，并在原位置短暂说明原因。

确认交接必须原子地修改归属：同一 NPC 只有一个 owner，保留坐标、人物身份和原伤势；交出队不再拉动此人，接手队不会把人瞬移到自己的目的地。接手队等待玩家新指令，避免沿旧命令把伤员带走。取消或暂停中断选择，不改变归属。队伍成员转队与 NPC 交接是两个操作，不能混用。

护送队全灭时，NPC 留在当前合法位置等待接应，不消失、不自动到营地。现有 NPC 并非直接承受普通投射物的攻击目标；本切片先沿用这一点，危险来自护送战力、路网和后方防守。若之后要加入伤员可死亡规则，需另做可读预兆和难度设计，不在多目标接入时暗中添加。

### 胜败、中断与恢复

- 成功：两位指定目标 ID 都在抵达集合中，且全局失败尚未成立。
- 失败：沿用博士十次命中、补给碑全毁/开门前目标所需完好碑不足、队伍全灭且无最低补员资源等当前规则。多人目标要求全部检查，不因开了 A 门就忽略 B 门已不可完成。
- 队伍倒下但仍可补员：目标原地等待，玩家可恢复接应；不得形成无反馈的永久等待。
- 暂停：移动、开门、交接和人机计时一并冻结；关闭窗口或重载仍从本关开头重来，保留已经完成的其他关卡。最小版本不承诺中途存档。
- 重试：清空本局抵达和交接临时状态，重建人物 ID；不重复写角色解锁或奖励。

### 植物人机、动作和最低界面

人机依据可见小队、可见护送对象与公开补给情况安排防线，继续支付真实阳光、遵守卡片冷却及至少三秒的换行间隔；攻击遵守原植物身份。不能读取博士秘密位置、玩家未执行的路径终点或隔雾目标。第二人出门不会凭空生成免费植物。

需要的最少美术：两枚不同头像/姓名的小门牌、释放和等待动作、慢行与交接伸手动作、营地两个抵达标记。复用当前伤员脚圈与残血姿态，不增加常驻人物血条。关键反馈只有“已交接”“已抵达 1/2”和当场失败原因。

验收重点：A/B 任意顺序、同时开门、首人抵达不结算、交接中队伍死亡、隔水拒绝、NPC 等待再接、多人同格、暂停/重试、重复抵达不重复奖励，以及旧单目标结算没有回归。

## 优先切片二：证据运输

建议入口：L3-5 后的地下插章《饭盒上的章》。两份记录分别是食物采购账和宣传处涂改记录，另有一名普通见证人需要接回；呈现“他们吃的只是普通食物”的具体生活证据。揭示诬陷，不提前揭晓幻想真相。

### 物件和操作

复用双目标的目标账本，新增两份有稳定 ID 的实物记录。每份经历：封存 → 地上 → 携带 → 已交付。携带者记录为成员 ID，不记录“队伍一”，避免转队、合并、分开后复制或丢失。

首个切片限定一名成员一份、一队最多一份；在场景中显示纸袋背挂和地上的文件束。点击文件柜，队伍到达后停留两秒取件；两秒是后续切片的初始设计值，须在实际开发时平衡，不修改当前战斗值。离开交互距离、开始其他命令或承载者失效时取消本次取件计时，下次重新计时；暂停冻结，不取消。

拿到后，成员转入另一队时物件跟随这个真实成员 ID，目的队已经运送一份则拒绝该次转移，并短暂提示。联队仍保留各子队和各自物件，合并不自动拼成一个库存，分开也不会复制。这个限制只用于将来的运输切片，不改变现有关卡成员转队。

携带者倒下时，原子地清除 carrier、生成唯一地上物件。落点选择倒下处最近的合法可接近地面，稳定规则打破等距；不得穿墙回营。地上物件不会被普通子弹消灭。实际进入营地并停留两秒后交付；校验真实携带者、物件 ID、距离及未交付状态，再一次性提交。接近营地但仍隔墙、飞过营地或另一支空队先回来均不能代交。

最小地下切片出现在气球解锁之前，先用已有普通、路障、纱门、铁桶测试陆路搬运，不顺便扩张空运、潜水打捞或复杂货物重量系统。未来水域掉落另设可达岸边/打捞规则，不套用陆地吸附逻辑。

### 结果、中断与恢复

- 成功：两份记录交付且见证人实际抵达；目标账本一次性完成。仅取出文件、击败守卫或送回一份不算成功。
- 失败：沿用当前全局失败规则；必须检查剩余必要物件与人物是否仍有可完成路径。动态通路造成永久不可达时，先执行有定义的恢复落点/返航规则，确实无法恢复才明确失败，不能悬着不结束。
- 被打断：取件/交付尚未提交时不消耗物件；已经提交不重复领取奖励。死亡掉落与取件完成在同帧时采用统一事件顺序，先校验生存资格，再提交携带。
- 暂停冻结交互；重载从本关开头重新放置两份物件和人物，只保留既有跨关存档。暂不提供半局物件恢复，避免误称已有检查点系统。

人机只对已观察到的携带纸袋和返程队伍作反应，不能读取藏在柜中的未公开记录或鼠标目的地。允许用付费防线牵制返程、从无人回应的行缓慢换路；遵守阳光、冷却、合法底座、同行攻击及博士信息隔离。任务结束后停掉调度，不能继续种植或连发结算。

最少界面只有柜子封条、携带纸袋、地上文件束、营地纸堆和短暂“已交付 1/2”。选中携带队伍的小行动牌可显示一枚文件图标；不增加运输侧栏。动作需求为开柜、拾起、背负慢行、掉落、交付，攻击/受击不令纸袋离开成员锚点。

验收重点：死亡前后同帧取件、地形合法掉落、拾回同 ID、转队/合并/分开守恒、抵营中断、重复交付、暂停、重试、见证人与文件不同顺序，以及两项已完成而第三项未完成时不提前胜利。

## 其余任务先保留概要

有限反扑先做三批明确预告，锁定危险行后不追踪玩家尚未执行的换线。预留的植物仍付真实阳光和冷却；最后一批结束后不暗加无穷增援。分批撤离复用逐人账本，公布批次数，各批间短暂停顿整理，全部抵达才结算。两者都需要任务不可完成判断和暂停安全的调度。

巨人关必须保留一条初始旁路，先救人再使用能力。指定可搬障碍用场景木料标识，搬动途中有明确受击和中断表现；更新连通图后重新验证队伍、跟随者和返程，不让已经在桥上的人落入非法坐标。巨人能否占一个编组槽、是否独立任务单位，需要该切片阶段比较体型与成本后确定，不能直接用现有大图标顶替规则。

矿工先实现入口、钻地、地下行进、出土、攻击五阶段，逐阶段明确可达、可见与受击资格，不能任意隔墙交付。扶梯先做一处标记障碍，架设、通过、损毁均更新真实路网，护送者仍须实际行走。潜水补齐下潜和接敌浮起，视觉姿态与减伤资格同一状态驱动；桥面不能误判为水下。之后再增加橄榄球冲锋，不一起展开全部图鉴能力。

打捞复用物件账本，工位完成后真正生成组件再搬运。驳船有固定停靠、货物归属及回退码头，闸门变路前预告，不让接手者抵岸触发货物瞬移。供电维修需要驻留，离开中断、暂停冻结，照明范围明确；故障不能靠不可见倒计时突然判负。吊篮沿用停靠/交接约定，屋面盆与坡面弹道继续独立处理，角色脚点锚定到平台实际高度。迷雾侦察先补双方观测裁剪与已知区，不靠给 AI 全图信息制造难度。

## 巨型机甲与现有失败规则的衔接

现有营救是“博士秘密藏在某段栅栏后、十次命中、三队行动”。经典巨大机甲由博士公开驾驶，二者不能无说明地混成同一种规则。建议将机甲设为后续独立遭遇类型，在进入该任务前明确切换，现有四十关的藏身和失败规则保持原样。

1. 第四幕先用组件任务逐项学习冰火对消、预警踩踏和支援调遣；第五幕才合并成完整巨型战。普通队继续是有姓名的支援者，不将小鬼当一次性弹药。
2. 驾驶员仍以十次有效命中为唯一生命计数，不另加一根有独立致死条件的机甲血条。同一局切阶段继承当前剩余次数，不靠变身回满；如果是明确的新一关，按新局正常初始化十次。
3. 机甲阶段的驾驶舱是公开目标，人机依据公开暴露窗口攻击；不能一边画博士坐在机甲上，一边仍要求人机不知道他在哪段栅栏。此处是未来新规则设计，本轮没有实施。
4. 栅栏转为营地支援设施，不通过任意栅栏受损给机甲博士扣命。保留补给线失守的失败压力，按新任务定义所需补给目标；不能同时存在旧栅栏扣命和新驾驶舱扣命两条隐藏路径。
5. 大招有清楚前摇、落点、恢复窗口；体积、影子和分层肢体避开三队、开门物件与操作区。巨大机体不是把现有小博士整张放大。
6. 统一终止门处理命中归零、支援目标失败或后院目标完成。同帧胜败先评估驾驶员与必需支援是否仍满足生存条件，再提交胜利，一次性冻结战斗，禁止重复结算。

四款文化造型共用骨架、攻击事件、点击区、阴影和数值。先完成经典机甲，再用青铜机关做首套实战换装，随后砂金与蒸汽。现有平面展示图只作美术参考，需另制分层头、驾驶舱、机械臂、脚、冰火发射与倒地零件，不能冒充已完成动画。

## 故事真相与分支边界

抓捕和序章电刑真实。越狱击倒守卫、同族营救开始即进入持续幻想；四十关及后续集结、研发、战争都在这一层内。植物和人类对外貌的厌恶、普通口粮被污名成吃脑子，通过具体人物和物件呈现；没有证据任务把现实囚室变成已经逃脱。

第五幕幻想胜利保留“我们做到了……苦难到此结束”。台词后配乐切断、白光消散，回到相同束缚和电极。和平选择醒后更重失落，强攻选择留下伤亡愧疚，毁灭选择落入无路可走的自语；均不改变现实从未离开房间。结尾不怒吼反转，以安静怅然收束。字幕后电极重新充电，意识下沉，暗示下一轮幻想。

后续开发先交付双目标的一关，再交付证据运输的一关；完成其规则、动作和旧关回归后才推进其余表中项目。设计文档不重新挂回正式游玩窗口。
