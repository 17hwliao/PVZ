## 入口与范围

从主菜单「同胞与故事」进入「八境营救·四十关」，或打开 `game/terrain-campaign.html`。默认逐关解锁，独立保存到 `pvz-terrain-campaign-v1`，不改旧冒险和旧七关存档。地图册各场地可进入对应地图的试演关；试演全关开放，但不写正式进度。

草地、夜晚、地下工坊、泳池、迷雾、水渠、屋顶、夜屋顶各五关，共四十关。每关有不同路线、三段来信、开门交谈及返营回应，四十名待救者各自命名。当前四十关均采用「接通补给—开门—护送返营」目标；十二类玩法中的多目标运输、吊篮、船闸、巨人搬运和巨大机甲仍是后续设计，没有将美术预览冒充新玩法。

## 场外向日葵（最新用户规则）

- 五株放在原小车一侧的场外石径，模型列坐标为 −1.15，各行一株，免费随新局刷新。
- 独立存入 `economySunflowers`；不在可攻击植物集合内，不参与寻敌、近战、AI转移、战斗占格、种植上限或开门争夺，始终保留生产能力。
- 开局500阳光完整保留，五株不扣费，池水与屋顶也不需要为它们购买睡莲或花盆。
- 延续现有准备规则：60秒布阵时不产阳光；开战12.5秒首次产出，之后每25秒各产25阳光。暂停、读信与结算冻结生产。
- 场内后续植物仍正常付费；四十关场内植物上限为3—7株，等于此前包含五株向日葵的8—12总量扣去固定经济列，避免此次移出战场后突然多出五株火力。

旧七关小队模式也采用该场外经济列。原冒险的反向塔防独立模型不受本次调整影响。

## 地形实际效果

| 场地 | 已实现的效果 |
| --- | --- |
| 草地 | 正常地面路线；昼间天空阳光；蘑菇睡眠，咖啡唤醒后才攻击或生产 |
| 夜晚 | 蘑菇自然清醒，阳光菇15阳光、成长后25；不产天空阳光 |
| 地下 | 同胞与护送目标移动速度×1.2；植物换行速度不加快 |
| 泳池／水渠 | 非桥水格限制通行；纯水生队能游泳，混入陆生队员或护送陆生伤员必须走岸桥；水上植物先付25阳光睡莲 |
| 迷雾 | 实际遮挡雾外植物、底座和弹丸；双方观察范围有限；路灯花照亮附近；三叶草预警2.5秒后吹走空中气球、清雾30秒 |
| 屋顶／夜屋顶 | 场内种植先付25阳光花盆，底座被破坏上层植物退场；屋脊截住低位直射，卷心菜同行抛射可越过；昼夜睡眠规则继续生效 |

保留五行十列，泳池没有扩成经典六行。屋脊是与现有网格相容的阻挡规则，非原版所有角度物理的复刻。雾区目前按格判定可见，视野边缘仍可看出网格，不是连续流体雾。

植物保留身份：豌豆／寒冰直射同行，倭瓜察看、起跳、落点压砸一次，大嘴花吞食后咀嚼，仙人掌升高对空；小喷菇短射程，大喷菇同行穿透，咖啡只唤醒睡眠蘑菇。植物可以慢速换行，至少三秒一格，弹丸不跨行追踪。

花盆和睡莲有独立费用、冷却与实体状态；准备期可连续布阵，但仍扣阳光，提前出发承接剩余冷却。

## 角色成长与资源

兵种由初始普通，依次解救路障、纱门、铁桶、游泳圈、潜水、气球、矿工、梯子、橄榄球。新类型只在营救成功后的关卡可编入，不允许在自己的营救关提前使用。出发编组预算按区域450→1045，最多三队各三人；后续补员仍消耗应急物资。

纱门减免正面直射，潜水在非桥水中且未近身时减免直射，穿透与抛射克制这些优势。水生行走已实现；矿工地底潜行、梯子攀越、橄榄球冲撞与潜水完整浮潜动作没有接入这套新模型，界面职责文字不再承诺这些能力。梯子／橄榄球目前沿用既有骨架与类型标记，不能称为完整经典动作交付。

新增九种原生植物骨架／底座及72份原版拆件，保留来源和哈希。补齐实际睡眠、成长、攻击、咖啡和吹风片段；小型蘑菇的花盆脚点重新上提，盆沿位于根部前方。修复雾外睡莲泄露、雾图逐格重复纹理条带、卷心菜弹丸误画成普通绿点的问题。

数值参考本地经典资源及 [Plant.cpp 源码参数](https://github.com/ruslan831/PlantsVsZombies-decompilation/blob/master/Lawn/Plant.cpp)，属于营救模式适配；未宣称当前可执行文件的所有隐藏参数逐项一致。

## 已修复的通关阻塞

1. 场外不可达的非攻击向日葵曾阻止开门；当前经济列完全退出战斗集合，场内非攻击生产者也不会凭空成为守门武器。
2. 门与补给碑夹出的不可达孤格曾被AI种入守卫；部署和转移现在要求与有效路线连通，不扣失败落种的费用。
3. 水生队曾在无桥水面接出陆生伤员，接人后全部命令失效。现在必须在适合获救者站立的相邻岸桥格接应，开门后清除旧水路；无效接应明确提示，没有用传送绕过规则。
