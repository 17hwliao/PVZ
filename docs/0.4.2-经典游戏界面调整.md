# 0.4.2 经典游戏内界面调整

对应反馈：0.4.1虽然加入原版贴图，但卡槽、图鉴底板、工具栏的比例与组合仍偏离经典游戏。此次继续修改同一阶段的视觉实现，机制、故事与序章漫画不变。

## 已实现

- 顶部卡槽从屏宽55.75%缩为44.6%，保持原SeedBank的446:87比例；僵王能量与五个卡位一并缩放。
- 常驻按钮收拢为暂停、菜单；作战来信和动作图鉴放入菜单，保留原功能及暂停/恢复状态。
- 草坪上移除重复胜利说明和额外工具面板，关卡标题集中在上方，选中单位信息放在下沿。取消网页式页脚，画面居中显示。
- 选卡使用原版SeedChooser木框比例465:513。资料不再把800×600的整本图鉴底板压进小面板，改用原版Almanac_ZombieCard石卡框与Almanac_GroundNight底图；仅延展空白文字区80像素。
- 卡片保留原边框、草地与纸面，以原纸面覆盖内置英文占位标题，再叠加可访问的中文单位名；不把占位英文和中文压在一起。
- 菜单沿用原版墓碑菜单底图，主返回使用原返回游戏按钮。按钮保持正常/按下状态；未解锁章节和空卡组继续禁用。
- 窄视口资料区独立滚动，可键盘聚焦阅读；编组按钮固定在资料卡底部。矿工长说明的滚动与不可提前解锁行为已核对。
- 墓碑耐久数值移至血条左侧，避免前一座的数字被后一座墓碑覆盖；植物、僵尸仍不显示血条。

本轮没有生成新的AI界面插画，没有改动植物与僵尸美术；使用用户提供经典版资源与常规HTML/CSS/Canvas排布。场景为保留反向塔防的五行与墓碑列而适配，非原版EXE、非逐像素复刻。资源来源与派生方式记录在game/assets/ui/original-provenance.json，27张原贴图有SHA256证据。

## 验证范围

实际浏览器检查1280×850与844×390：首封来信、选卡、未解救矿工资料、资料键盘滚动、开始战斗、召唤、菜单、动作图鉴与返回。窄屏六个菜单出口均处于视口内，开始与编组按钮可见；长资料可以独立滚动。浏览器尺寸检查不等于安卓设备体验。

复用已有71项行为检查，工具测试首条改为从真实菜单“动作图鉴”进入，并核对返回菜单焦点；另检查语法、原纹理哈希和全部资源引用。没有新增全项目Review，也没有把模拟或打包当作原生Windows/Android实测。

旧0.4.1包保留；0.4.2使用独立构建号、同一APK签名、本地打包。最终打包与内容哈希见交付校验清单。
