# PVZ：僵王崛起 · 0.8.0

经典素材独立实现的反向塔防与小队营救游戏。当前源码将重绘序章、来信和八境四十关接入经典单窗口；正式营救界面已精简为顶部操作区、左侧敌方情报牌和场景小队交互。它是独立程序，不是原版EXE补丁。

## 游玩入口

本地开发默认使用 **Electron 桌面窗口**：双击根目录 `Start-Electron.cmd`（`Start-Game.cmd`、`game/Start-Slice.cmd` 同样进入桌面），或运行 `npm start` / `npm run dev`。已配置当前电脑的本地 Electron 运行库；不需要启动 HTTP 服务。网页预览仅用于辅助排查，使用单独命令 `npm run start:web`。

源码启动需要 Node.js 和 Electron 运行库。换电脑时可先安装开发依赖 `npm install --no-save --package-lock=false electron`，或通过环境变量 `PVZ_ELECTRON_PATH` 指定已有的 Electron 可执行文件；也可在忽略提交的 `.private/electron-runtime.json` 配置 `{"executable":"绝对路径"}`。源码启动使用独立的 `ZombossRise-Dev` 存档目录；正式包继续使用 `ZombossRise`。F11 切换全屏；修改源码后关闭并重新启动桌面窗口以加载新内容。正式包不需要用户安装 Node.js 或 Electron。

- **八境营救·四十关**：草坪、夜晚、地下、泳池、迷雾、水渠、屋顶、夜间屋顶各五关。主菜单有直接入口，也可打开`game/terrain-campaign.html`。
- **营救攻防·七关小队行动**：`game/rescue-design.html`，保留三队调遣、开门与护送。
- **经典对线序章与前两章**：主菜单“经典对线”，保留开局电刑、漫画、来信和分支。
- **完整经典图鉴**：49种植物与26种僵尸的形象、职责和手记。尚未加入实战的角色会明确标注；图鉴数量不等同于全部经典机制已还原。
- **地图与战役册**：`game/battle-atlas.html`。其余进阶任务、经典巨型机甲和最终梦醒实战仍为设计。

水域与固定桥、睡莲／花盆、蘑菇昼眠／咖啡、阳光菇成长、雾中视野、三叶草、地下移速、屋脊直射与抛射差异均已进入四十关。各模式分开保存进度，不能混用胜负或存档规则。

小队可直接点击人物或脚圈选取，同格木牌支持选择、合并与分开。植物按500开局阳光、五株免费场外无敌向日葵及卡片正常费用冷却部署；只沿自身列慢速换行，射击仍限定所在行，不读取博士藏身处。全部已夺取完好墓碑均可花物资回血和补员。

主菜单“开始冒险模式”进入四十关；首次从序章漫画接到来信，随后直接准备。点击人物或顶部图标选队，点击格子下令；小“行动”木牌保留驻守、汇合、转队等命令，同格可选队、合并、分开。点击已接通近碑补给，准备时点击栅栏指定博士，再出发。鼠标所在格实时提示落点。编队、信件回看、选关和设置集中于对应游戏弹窗，正式战场不显示指南、设计页、侧栏或底部日志。

## 下载、版本与更新

[下载PC便携包／签名Android APK](https://github.com/17hwliao/PVZ/releases/latest)。Windows需完整解压后运行ZombossRise.exe；Android要求8.0以上及支持现代网页功能的系统WebView。本版统一0.8.0／构建800，沿用包身份与原Android签名。

主菜单和营救页面可检查新版本，显示版本与构建号，发现新版后由玩家打开对应平台下载。当前实现为检查与下载入口，安装由玩家确认完成；不会静默替换程序。首次具有此功能的版本为0.7.0，此前离线版本需手动更新一次。

## 源码与构建

`game/`为游戏，`desktop/`为Electron容器，`android/`为原生WebView容器，`tests/`为自动检查。网页开发可用HTTP静态服务器打开game目录；使用Node.js22.22.2、24.15.0或兼容更新版运行`npm ci`、`npm test`。

`release/version.json`统一管理版本与构建号，`node tools/sync-version.cjs`同步各端。`Build-Local.ps1`使用Electron ZIP、Android SDK、JDK及单独保管的原签名私钥构建。运行库、node_modules、签名密钥、密码与二进制工件不进入源码仓库。
