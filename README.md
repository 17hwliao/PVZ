源码目录：game/为完整游戏，desktop/为Electron容器，android/为WebView容器，tests/为自动检查。直接打开game/index.html可运行网页版本。运行npm ci后npm test执行79项行为检查及语法/资源一致性检查。

PC与APK由Build-Local.ps1使用本地Electron、Android SDK和单独保管的签名密钥构建。签名密钥、密码、运行库、安装包和node_modules不进入仓库。0.5.0已在浏览器实际通过首关，并核对桌面与窄视口流程；Windows游戏窗口与Android设备体验仍未验证。

当前为独立实现，非原版EXE补丁；巨人、机甲、最终梦醒等后续内容尚未制作。
