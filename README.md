# PVZ：僵王崛起 · 0.7.0

经典素材独立实现的反向塔防与小队营救游戏。本版整合0.6.0之后的角色、故事、八地图长线、调遣、植物人机与补给修复，并加入PC／Android版本检查。它是独立程序，不是原版EXE补丁。

## 游玩入口

- **八境营救·四十关**：草坪、夜晚、地下、泳池、迷雾、水渠、屋顶、夜间屋顶各五关。主菜单有直接入口，也可打开`game/terrain-campaign.html`。
- **营救攻防·七关小队行动**：`game/rescue-design.html`，保留三队调遣、开门与护送。
- **原冒险序章与前两章**：主菜单开始／继续，保留开局电刑、漫画、来信和分支。
- **完整经典图鉴**：49种植物与26种僵尸的形象、职责和手记。尚未加入实战的角色会明确标注；图鉴数量不等同于全部经典机制已还原。
- **地图与战役册**：`game/battle-atlas.html`。其余进阶任务、经典巨型机甲和最终梦醒实战仍为设计。

水域与固定桥、睡莲／花盆、蘑菇昼眠／咖啡、阳光菇成长、雾中视野、三叶草、地下移速、屋脊直射与抛射差异均已进入四十关。各模式分开保存进度，不能混用胜负或存档规则。

小队可直接点击人物或脚圈选取，同格木牌支持选择、合并与分开。植物按500开局阳光、五株免费场外无敌向日葵及卡片正常费用冷却部署；只沿自身列慢速换行，射击仍限定所在行，不读取博士藏身处。全部已夺取完好墓碑均可花物资回血和补员。

## 下载、版本与更新

[下载PC便携包／签名Android APK](https://github.com/17hwliao/PVZ/releases/latest)。Windows需完整解压后运行ZombossRise.exe；Android要求8.0以上及支持现代网页功能的系统WebView。本版统一0.7.0／构建700，沿用包身份与原Android签名。

主菜单和营救页面可检查新版本，显示版本与构建号，发现新版后由玩家打开对应平台下载。当前实现为检查与下载入口，安装由玩家确认完成；不会静默替换程序。首次具有此功能的版本为0.7.0，此前离线版本需手动更新一次。

## 源码与构建

`game/`为游戏，`desktop/`为Electron容器，`android/`为原生WebView容器，`tests/`为自动检查。网页开发可用HTTP静态服务器打开game目录；使用Node.js22.22.2、24.15.0或兼容更新版运行`npm ci`、`npm test`。

`release/version.json`统一管理版本与构建号，`node tools/sync-version.cjs`同步各端。`Build-Local.ps1`使用Electron ZIP、Android SDK、JDK及单独保管的原签名私钥构建。运行库、node_modules、签名密钥、密码与二进制工件不进入源码仓库。

## 已验证范围

本轮打包前的营救基线267项检查通过，全部40关有合法通关模型证据；其中两关需更换策略，原失败记录保留。本版整合后300项Node检查通过，另有Android检查器50条行为断言及10条桥接静态契约检查。跨端构建会核对实际版本、签名、全部游戏文件与校验和。

自动检查与画布导出不等于真人难度、整页视觉、Windows真实窗口或Android实机升级验收。当前Work设置禁用本地浏览器，最新整页与窄屏体验仍有验证缺口，历史浏览器结果不证明本次四十关入口已经验收。
