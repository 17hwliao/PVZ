## 启动与操作

Windows包解压完整文件夹后运行ZombossRise.exe，F11切换全屏。Android APK要求Android8.0以上与支持现代网页特性的系统WebView，横屏运行。源码中的Start-Slice.cmd打开离线网页版，也可直接打开index.html。

主菜单开始或继续营救。战前点击下方已解救卡加入，点击上方卡移除；右侧预览植物防线，单位详情按需打开。实战选择僵尸卡，点击右侧行入口召唤；1—5选卡，方向键选行，回车召唤，空格暂停；右键/Escape取消召唤。“菜单→设置与档案”可重读本关来信或查看动作图鉴；打开时暂停实战，关闭后保留原来的手动暂停状态。

## 植物与僵尸

植物包括远程豌豆、寒冰控制、坚果阻路、向日葵支援、仙人掌对空、大嘴花近战。向日葵每6秒恢复同行180范围内其他存活植物18耐久，不能复活或修复自身。大嘴花前方95范围内蓄力0.45秒咬击90，休息4.5秒，不能攻击空中或地下。

植物和僵尸均以亮闪、姿态、裂纹/护具破损、攻击预兆和退场表现状态。图鉴包含六种植物42个阶段及五种僵尸的受击、护具、寒冰、触电、爆裂/出土与倒地。柔和设置减少后缩、摇摆与碎片。退场演出不参与碰撞或挡弹。

保存章节、卡组、解救、来信、分支和序章状态，兼容旧0.2/0.3进度。战后救援/漫画退出可接续；进行中的战斗下次从本关开局重来。Windows数据在%APPDATA%/ZombossRise，Android在应用私有存储；不同平台不自动同步，卸载Android会删除存档。损坏存档保留原文，不静默覆盖。

## 营救攻防 · 小队行动

入口为「同胞与故事」→「营救攻防·小队行动」，或打开rescue-design.html。独立试玩有七种篱墙缺口布局与开门、护送返程胜负，保持原冒险存档独立。

每局有60秒准备期，玩家从本关已解救兵种自由配置固定三队、每队最多三人，并在栅栏前第9列布阵。提前出发后配置锁定，可随时无冷却调遣；两队会合可以转队，伤势保留。准备区也可预排行军命令。

植物AI初始有500阳光，并免费配置原小车位置的五株场外经济向日葵。五株无敌、不占棋盘格、不挡房门与队伍、不占战斗植物上限，不需要水面／屋顶底座。其他场内植物通过真实付费种植，准备期不限制种植冷却，但提前出发后保留卡片剩余冷却；战斗期普通卡7.5秒、坚果与倭瓜30秒。场外向日葵战斗中产阳光，机器人按预算补种。

植物保留经典攻击身份：倭瓜察看后起跳压砸一次、落点锁定并退场；大嘴花吞下一名地面成员，完成闭嘴后咀嚼40秒；仙人掌升高发对空尖刺，刺破气球后回到地面姿态。普通豌豆与寒冰只打同行地面目标，弹丸不跨行追踪。向日葵只产阳光，坚果只阻挡。植物慢速换行与种植卡冷却分开，倭瓜保持伏击位置，大嘴花咬合时停下。当前实战接入七种植物，图鉴其他植物尚未全部加入战斗。

第10列五行各有独立600耐久栅栏。准备期先点击一段栅栏或指挥台木牌，指定博士藏身处；开战后锁定。未选择时60秒结束会等待指定，不自动替玩家选。植物人机只按公开战况布防与直射，不读取博士位置，空栅栏击穿后仍正常朝本行射击。只有藏身行栅栏击穿后，后续命中博士才按10次独立计数扣除。获救同胞有独立重伤姿态、护送木牌与金色脚圈。结算后默认8秒自动刷新新一局，可取消自动刷新查看结果。

界面沿用经典木石素材；墓碑、房门实体占位，队伍在相邻格交互，植物和僵尸不显示血条。本次未打包。生产画布已检查；2026-10-25另核对实际浏览器的故事册桌面／窄屏显示及桌面部署页，真人战术难度和原生设备体验仍未验收。当前规则、数值来源与素材来源见源码docs/营救攻防-关卡与战场展示.md和assets/rescue-design/provenance.json。

## 2026-10-26 八地图四十关实战

独立入口为 [terrain-campaign.html](terrain-campaign.html)。按草坪、夜晚、地下、泳池、迷雾、水渠、屋顶、夜间屋顶顺序各五关，共四十名独立获救者。每关保留三队、60秒准备、亲自指定栅栏后博士藏身行、接通补给、开门和真实护送回营。新增关卡全部是单人护送，不把故事中的船运、起吊、批次撤离或机甲字样称为已完成任务机制。

水域只允许普通队经过固定桥；全队有水面能力时才增加水路，混入普通队员或护送地面伤者就须考虑桥。非桥水格先付25阳光种睡莲，屋顶先付25阳光种花盆，再种本体；底座独立受击。白天蘑菇睡眠、咖啡付费唤醒，夜晚自然醒，阳光菇成长后产量提高。迷雾使用小队／植物观测范围，路灯花照明，三叶草预警后清雾并克制空中气球。地下移动速度提高，屋脊可挡低位直射，卷心菜按同行抛射越坡。保留营救模式自己的平衡，未声称逐项复刻经典版本。
