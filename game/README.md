# 僵王崛起 · 前两章 0.4.2

以经典资源独立实现的反向塔防，包含20句/163秒、12格完整绘制分镜的序章、两章七关、七封开场信、八处Q版漫画分镜、五种可解救僵尸和第二章末的和平/强攻分支。采用经典植物、僵尸与木石UI；不是原版EXE补丁。

## 启动与操作

Windows包解压完整文件夹后运行ZombossRise.exe，F11切换全屏。Android APK要求Android8.0以上与支持现代网页特性的系统WebView，横屏运行。源码中的Start-Slice.cmd打开离线网页版，也可直接打开index.html。

选择已解救僵尸卡，点击右侧行入口召唤；1—5选卡，方向键选行，回车召唤，空格暂停。右上角“菜单”内的“作战来信”重读本关提示，“动作图鉴”切换植物/僵尸图鉴；打开时暂停实战，关闭后保留原来的手动暂停状态。

## 植物与僵尸

植物包括远程豌豆、寒冰控制、坚果阻路、向日葵支援、仙人掌对空、大嘴花近战。向日葵每6秒恢复同行180范围内其他存活植物18耐久，不能复活或修复自身。大嘴花前方95范围内蓄力0.45秒咬击90，休息4.5秒，不能攻击空中或地下。

| 僵尸 | 费用/冷却 | 耐久 | 机制 |
|---|---|---|---|
| 普通 | 50 / 3秒 | 210 | 低成本先锋 |
| 路障 | 100 / 6秒 | 430 | 三级护具破损，护具耗尽后保留210本体 |
| 铁桶 | 150 / 9秒 | 650 | 重甲，更慢，三级护具破损 |
| 气球 | 125 / 10秒 | 180 | 绕地面和小车，不挡地面弹；仙人掌击破气球后落地 |
| 矿工 | 175 / 12秒 | 240 | 潜至520出土，停顿1.2秒；地下不挡弹 |

单位伤害均为46/秒，能量自然恢复4.5/秒。寒冰移速×0.65、2.5秒刷新，不叠乘。前两关只有普通，之后逐关解救并加入编组；不能在自己的救援关先使用尚被关押的兵种。

植物和僵尸均以亮闪、姿态、裂纹/护具破损、攻击预兆和退场表现状态。图鉴包含六种植物42个阶段及五种僵尸的受击、护具、寒冰、触电、爆裂/出土与倒地。柔和设置减少后缩、摇摆与碎片。退场演出不参与碰撞或挡弹。

## 故事与存档

僵尸吃普通食物；长相被用作诬陷依据。序章营救队的铁桶阿铆随后护送伤员，粮仓中待救的是另一位老兵老周。开局信件连接救援、工坊、转运单和宣传所，漫画按故事节点播放，也可在档案回看。前两章不揭晓最终梦醒；后续城镇、巨人、机甲和终局尚未实现。

保存章节、卡组、解救、来信、分支和序章状态，兼容旧0.2/0.3进度。战后救援/漫画退出可接续；进行中的战斗下次从本关开局重来。Windows数据在%APPDATA%/ZombossRise，Android在应用私有存储；不同平台不自动同步，卸载Android会删除存档。损坏存档保留原文，不静默覆盖。

## 实现与验证边界

游戏运行完全离线；PC启用Electron沙箱和上下文隔离，APK使用本地WebView资源拦截，无联网、存储或相机权限。二进制构建不需要npm；自动测试需要Node.js与jsdom，详见根目录构建说明。

0.4.0已审查游戏代码、全部当前故事与漫画、资源引用、界面返回、存档、容器和构建脚本；五处已确认问题均已修复并添加回归检查。程序模拟、实际角色画布渲染、构建、签名与内容哈希分别记录证据。0.4.1补充实际浏览器1280×850及844×390尺寸检查，修复卡片压缩、档案文字重叠及菜单定位；浏览器日志未见错误。Windows游戏窗口和Android设备运行仍未验证。

0.4.1将旧几何囚室完全替换为三张Q版彩绘图集，补齐威逼、电刑挣扎、脱力和营救动作。动作以独立绘制关键姿势和镜头转场演出，非逐帧角色动画。战斗UI复用原版23张贴图，保留反向塔防所需的僵王能量与墓碑显示；不是原版界面的逐像素复刻。

0.4.2继续按经典版调整游戏内构图：卡槽恢复紧凑比例，常驻工具只留暂停与菜单；来信和图鉴归入菜单。选卡沿用原版木框，资料改用原版僵尸图鉴石卡框，保留纸面与笔触，不生成新UI插画。窄屏资料区可滚动阅读，编组按钮固定可达。原版卡片英文字样使用同贴图的纸面区域处理，避免与动态中文名称重叠。
